# NSSQ 시스템 사용 설명서

「SRS가 아닌 세계수의 미궁 TRPG」(NSSQ) 한국어판을 Foundry VTT v12에서 플레이하는 시스템의 사용법입니다.
규칙 자체는 룰북을 기준으로 하고, 이 문서는 **어디를 누르면 무엇이 되는가**를 설명합니다.
원문에 없어 정해 둔 처리는 `docs/01-rules.md`의 §9(확정 사항)에 번호로 적혀 있습니다.

- 앞부분 1~3장은 **GM**, 4~8장은 **플레이어와 GM 모두**, 9~11장은 **GM 도구와 문제 해결**입니다.
- 표기: 【능력치·부능력치】, 《스킬》, [상태 이상], 『분류·강화/약화』, 〈속성〉.

## 1. 설치와 업데이트

- Foundry VTT **v12** 전용입니다(v13에서는 동작하지 않습니다).
- 설치: Foundry 셋업 화면 → 게임 시스템 → 시스템 설치 → 아래 매니페스트 URL을 붙여 넣습니다.
  ```
  https://github.com/Nomal-1/nssq-fvtt/releases/latest/download/system.json
  ```
- 업데이트: 셋업 화면의 게임 시스템 탭에서 업데이트를 누릅니다. 월드를 켤 때 「월드 데이터 마이그레이션」 창이 뜨면 진행합니다.
- 업데이트 뒤 GM이 처음 접속하면 효과 데이터 동기화가 몇 초 걸립니다(월드에 있는 스킬·아이템의 효과를 새 버전에 맞춤). 잠시 기다린 뒤 진행하세요.
- 버그를 알릴 때는 「v0.x.y에서」처럼 버전을 함께 적어 주세요.

## 2. 처음 월드를 만들 때(GM)

1. 시스템을 NSSQ로 골라 월드를 만들고 GM으로 접속합니다.
2. 처음 켠 월드에는 **기본 마을 「뿌리 마을」과 미궁 「고목의 숲」·「눈 덮인 폐허」**가 자동으로 들어갑니다(예시용).
3. 컴펜디움에 클래스·스킬·장비·아이템·소재·에너미가 들어 있습니다. 직접 끌어다 쓸 수도 있지만, 대부분은 아래 창들이 알아서 꺼내 씁니다.
   - 컴펜디움 폴더 「NSSQ 룰북·가이드」: **플레이어 룰북(간결)**·**룰북(전문)**은 플레이어도 열 수 있고, **GM 기능 가이드**(이 설명서 + 원문 GM 섹션·샘플 시나리오)는 GM만 보입니다. 월드로 가져온 플레이어용 저널은 모든 플레이어가 관찰 권한으로 봅니다.
4. 플레이어 계정을 만들고, 각 플레이어가 캐릭터를 만들게 합니다(4장).
5. 그림·BGM은 저작물이라 시스템에 들어 있지 않습니다. 가진 파일이 있으면 [에셋 폴더 연결](11장)로 한 번에 붙입니다.

단축키: **Shift+G** = GM 스크린, **M** = 필드 지도(설정 → 조작 설정에서 바꿀 수 있음).

## 3. GM 스크린

**Shift+G** 또는 마을 화면 위쪽 GM 줄의 버튼으로 엽니다. 위쪽 [핫바에 매크로]로 핫바 버튼도 만들 수 있습니다.
상황(준비·마을·던전·전투)에 맞는 화면으로 자동으로 바뀌고, 위쪽 탭으로 직접 고를 수도 있습니다.

| 화면 | 주요 버튼 |
|---|---|
| **준비** | 필드 지도 만들기 · 직업/스킬/에너미 만들기 · 마을 관리 · 기본 마을·던전(원래대로) · 추가 컨텐츠 등록 · 에셋 폴더 연결 · 전투 구성 · 전투 프리셋 · 상점 품목(판매/숨김) · 파티(동료 NPC 지정) |
| **마을** | 마을로 · 세션 시작(【FP】 지급) · 상점 열기/닫기 · 판정 요청 · 필드 지도로 던전 진입 · 랜덤 던전 진입 · 생활비 · 세션 결과 |
| **던전** | 필드 지도 · 랜덤 던전 · 판정 요청 · 마을로 돌아가기 · 캠프 · 트랩 · 채집 · 지금 에어리어의 조우(랜덤 조우/구성 고르기) |
| **전투** | 전투 개시/종료 · 판정 요청 · 목표값 기준 |
| **참고표** | 목표값 기준 · 능력치별 판정 · 트랩 대미지 · 세션 경험점 · 레벨표 |

위쪽 상태 줄에 시각·낮/밤·어둠 속 전투 여부·던전 안 누적 전투 턴·상점 열림이 보입니다.

## 4. 캐릭터 만들기

- **작성 마법사**: 액터 탭의 [캐릭터 작성]을 누르면 7단계 마법사가 열립니다(플레이어가 누르면 GM이 대신 만들어 주고 그 플레이어에게 마법사를 띄웁니다).
  1. 기본(이름·그림) → 2. 능력치(3D6 굴림·배정) → 3. 클래스(메인·서브, 「간단히 보기」로 그림·진형 위주) → 4. 스킬 → 5. 장비(작성 모드 상점: 소재 없이 G만) → 6. 경력 → 7. 확인
  - 스킬: 메인·서브 클래스 스킬에서 합계 **SL 5**(Lv1은 한 스킬 SL 2까지), 커먼 스킬은 이와 따로 **하나를 SL 1**로.
  - 고유 스킬(★)은 메인 클래스에 따라 자동으로 붙습니다.
  - 완성하기 전에 창을 닫으면 「그만두고 지운다 / 계속 작성」을 묻습니다.
- **그림**: 시트 그림 칸을 누르면 그림 설정 창. [내 컴퓨터에서 올리기]로 올리면 GM을 거쳐 서버에 저장됩니다(플레이어는 파일 둘러보기 권한이 없어도 됨). 컷인 프레임·테마곡(♪)도 여기서 정합니다.
- 작성을 마치면 작성 내용이 잠깁니다. 이후 스킬은 **레벨업 직후**와 **길드 재분배·직업 변경 직후**에만 찍을 수 있습니다(GM은 언제나).

## 5. 캐릭터 시트

- **능력치 탭**: 능력치·부능력치. 능력치를 누르면 판정 창(Shift+클릭은 바로 굴리기). 마우스를 올리면 계산 내역.
  - [능력치 편집]: 굴림·클래스·성장·보전(추가 컨텐츠를 등록한 월드)·GM 보너스·장비가 칸별로 보이고, 굴림은 작성 중에만, 나머지는 GM만 고칩니다.
  - [레벨업]: 경험점이 다음 레벨에 닿으면 활성화. 누르면 【HP】·【TP】가 오르고 스킬 트리가 열립니다.
- **장비·소지품 탭**: 무기·갑옷·기타 슬롯, 소지 수, 소지금.
  - 아이템 줄의 아이콘: [사용](소모품) · [장비] · [기타 슬롯에] · [건네주기] · [창고에](창고 기능을 켰을 때) · [활성화](책·그리모어) · 지우기.
  - [상점]은 GM이 상점을 열었을 때만 눌립니다. [건네주기]로 다른 캐릭터에게 아이템·돈을 줄 수 있습니다(전투 중 제외).
- **스킬 탭**: 스킬 목록. 각 스킬 앞에 **[의존 부위][의존 무기] 아이콘**이 붙고, 그 부위가 봉인 중이면 빨간 사선이 그어집니다.
  - [스킬 트리]: 클래스별 트리. 선행조건과 남은 SL이 보입니다.
  - 「자동」 토글: 「사용을 선언한다」 계열(선택형 추격·반응 등)을 조건이 맞으면 묻지 않고 쓰게 합니다.
  - 『회복』 주행동 스킬은 전투 밖에서도 [사용]할 수 있습니다.

## 6. 마을

마을은 씬입니다. 화면 왼쪽 시설 목록을 누르면 시설 화면(그림·NPC·메뉴)이 열립니다. 시설 화면은 사람마다 따로 봅니다.

- 마을에 도착하면 전원 【HP】【TP】 최대, 상태 이상·강화/약화·오버히트 해제, 상점이 열립니다(여관·약방 무료 전제).
- **마을 BGM**: 마을 관리 → 마을 편집의 「마을 BGM」. 마을에 도착하면 그 전에 나오던 곡을 끄고 이 곡을 틉니다(비우면 끄기만). 곡의 「반복」을 켜 두면 계속 흐릅니다.
- **상점**: 탭별 품목. 「장비할 수 있는 것만」(기본 켬)으로 내 클래스가 못 드는 장비를 숨깁니다. 품목에 마우스를 올리면 랭크별 성능과 해설.
  - 무기·방어구: 랭크를 고르고, 대응 소재(그 R 이상) 1개 + 가격.
  - 소모품: 필요한 소재(정확히 그 R) + 가격.
  - 기동부적·향(추가 컨텐츠): 정해진 소재 종류 중 하나를 고르면 그 R의 아이템(가격 ×R²).
  - [매각]: 구입가의 절반, 소재는 (R²)×50G. [제련]: 장비당 2개, 3번째부터는 기존 효과 하나를 바꿔 끼움(비용 환불 없음).
  - 마을마다 판매 품목·판매 랭크 상한을 정할 수 있습니다(GM 스크린 「준비」 상점 품목, 마을 관리).
- **길드**: 스킬 재분배·직업 변경(경험점 −설정값, 기본 3. 레벨이 Lv1로 돌아가고 ★ 외 스킬을 돌려받아 작성 때처럼 다시 찍음). 캐릭터 대기(벤치) 전환.
- **파티 편성판**: 전위·후위 각 3칸 + 대기석. 정원 기본 5명(설정으로 6명까지). 플레이어가 [제출]하면 이동 투표와 같은 방식으로 승인합니다. 대기 중인 캐릭터는 파티에서 빠집니다.
- **미궁 입구**: 지도마다 [들어가기]. 플레이어가 누르면 GM에게 제안이 갑니다.

## 7. 미궁 탐색

### 필드 지도(베이직 던전)
- 미궁에 들어가면 지도마다 씬으로 바뀌고 화면 위에 메뉴가 겹쳐집니다(배경 = 지금 에어리어 그림).
- 메뉴: **이동**(투표 제안) · 조사 · 채집 · 캠프 · 지도 작성 · 지도 보기 · (입구에서) 마을로.
- **탐색 BGM**: 지도 편집의 「탐색 BGM」(지도 전체)과 에어리어의 「이 에어리어 탐색 BGM」. 미궁에 들어오면 이전 곡을 끄고 그 곡, 에어리어를 옮기면 곡이 다를 때만 바뀝니다. 전투가 끝나면 전투 전 곡으로 돌아옵니다.
  - 플레이어가 고르면 GM에게 확인이 갑니다. GM이 처리하지 않은 이벤트가 있으면 플레이어 메뉴는 가려집니다.
  - 이동 승인 방식은 설정 「필드 지도: 플레이어 이동」(모두에게 묻기 / GM에게만 묻기 / 바로 이동).
  - 도착하면 **나레이션 시간**: 플레이어 메뉴가 가려지고, GM이 미궁 화면의 [플레이어 메뉴 열기]를 누르거나 다음 행동(조사·이동 등)을 하면 다시 나온다. 설정 「필드 지도: 도착 후 나레이션 시간」으로 끈다.
  - 지도 편집의 에어리어 칸 「도착 나레이션」「다시 왔을 때 나레이션」에 글을 미리 써 두면, 나레이션 시간에 GM 미궁 화면에만 보인다. [채팅으로 읽기]를 누르면 에어리어 이름으로 채팅에 나간다.
- 지도(M 키): 플레이어는 보기 전용. GM은 [편집]으로 핀·통로·트리거·F.O.E. 루트·조우표를, [진행]으로 이동·되돌리기를 합니다.
- F.O.E.는 파티가 움직일 때 같이 움직이고(추적 포함), 같은 에어리어에 들어오면 전투입니다.

### 랜덤 던전
- GM 스크린 「마을」 [랜덤 던전 진입]. 시작 창에서 던전 레벨·무대를 정합니다.
- GM이 [다음 이벤트]를 누르면 플레이어 모두에게 2D6 팝업이 뜨고, 누구 하나가 굴리면 모두 닫히고 결과가 나옵니다.
- 클리어·[던전 나가기]로 마을로 돌아갑니다.

### 탐색 행동
- **채집**(GM 스크린 [채집]): 방법·양·랭크·결과표를 정하면 판정 카드 → 갈무리 풀.
- **캠프**: 캠프 창에서 요리·휴식 등을 정하면 시간이 흐릅니다.
- **트랩**: 대미지 기준은 참고표에.
- **시간**: 1시간마다 [독] 대미지·자연 회복·심도 −1·오버히트 감소가 결과 카드로 나옵니다. 던전 안 전투 30턴마다 +1시간.
- **판정 요청**(토큰 도구 또는 GM 스크린): GM이 판정 종류·목표값을 보내면 플레이어에게 팝업. 굴리기 전에 「2D6+11 → 20 이상이면 성공!」처럼 안내가 보입니다. 【FP】로 주사위 추가·다시 굴리기는 판정 창에서.

## 8. 전투

### 시작
- GM: 던전 화면의 조우 버튼, [전투 구성](배경·BGM과 에너미 목록), 또는 전투 프리셋의 [개시]. 개시 창에서 참가자·기습·식별 달성값·어둠 속 전투를 정합니다.
- 전투 화면(HUD)이 모두에게 뜹니다. 위쪽에 에너미, 아래에 파티 카드, 가운데에 행동 버튼이 있습니다.
- 에너미·캐릭터를 전투 화면에 끌어 놓으면 이 전투에만 난입합니다(위쪽 절반에 놓으면 후열).

### 화면 읽기
- 카드를 누르면 **자세히 보기**: 맨 위 「지금 걸린 것」(상태 이상·봉인·강화·약화·특수 상태·방어/대기), 에너미는 공개된 만큼의 능력치·스킬·DROP.
- 에너미 정보 공개는 이번 전투의 **식별** 결과대로입니다(도감의 처치 수가 기준 이상이면 자동 공개). 식별에 실패한 에너미는 ???로 보이고 내성을 최소 3으로 취급합니다.
- 간파하지 못한 **희소종**은 플레이어에게 원래 데이터로 보입니다(【HP】 막대가 0이 되어도 쓰러지지 않는 연출).
- 상태는 카드 위 연출로 표시됩니다(상태 이상 하나씩 점멸, 봉인 덩굴, 강화 붉은 테두리, 약화 보라, 방어 방패, 대기 금빛 점선 등).

### 개막 페이즈
- 각자 개막 행동 하나: **방어**(방어 전념) · **배치**(전후열 이동·위치 교환. 남의 캐릭터와 바꾸려면 그 조종자가 수락) · **무기 교체** · **스킬**(개막 스킬) · **아이템**(개막에 쓸 수 있는 아이템이 있을 때) · **행동 안 함**.
- GM은 [도주]·[식별 판정]·[개막 행동 되돌리기]·[다음]을 씁니다.

### 메인 페이즈(자기 차례)
- **[공격]** → 빛나는(사거리 안) 적 카드를 누르면 통상 공격. 다시 [공격]을 누르면 취소.
- **[스킬]**·**[아이템]** → 목록에서 고르기(위쪽에 해설·대상·사거리·코스트, 못 쓰면 이유) → 대상 카드 고르기. 범위·전체 대상은 바로 실행.
- **[턴 종료]**: 플레이어는 GM에게 요청이 갑니다.
- **굴리기 팝업**(플레이어의 공격): 공격·공격 스킬·공격 아이템은 대상을 고른 뒤 팝업이 순서대로 뜹니다.
  1. 명중 팝업: 「숲쥐: 2D6+5 → 9 이상」처럼 식과 목표값(식별 전 적은 ???), 【FP】 주사위 추가 칸 → [굴리기].
  2. 대미지 팝업(명중했을 때): 「숲쥐: 7D6 → 4 이상인 눈의 개수」(식별 전 적은 【내성】 ???) → [굴리기].
  - 명중을 굴리면 먼저 「명중 판정」 카드(주사위·달성값·명중/빗나감)가 채팅에 올라오고 전투 화면에 HIT·MISS가 뜹니다.
  3. 결과 카드(대미지). 대상·회차가 여럿이면 한 팝업에 모아 한 번에 굴립니다. 크리티컬 추가 다이스는 자동. 후발 행동·지연 공격처럼 GM 쪽에서 실행되는 내 행동도 내 화면에 팝업이 뜹니다(추격·반격은 바로 굴림). 설정 「공격 굴리기 팝업」으로 끌 수 있습니다(사람마다).
- **【FP】 주사위 선언**: 파티 카드의 FP 칸을 누르고 「+n」(명중 팝업의 기본값이 됩니다). 다음 공격의 명중 판정마다 n개를 더 굴려 높은 2개를 씁니다(늘린 판정은 【FP】를 얻지 않음).
- **【FP】로 다시 굴리기**: 공격·스킬 카드의 명중 줄마다 버튼(판정당 1번). 그 카드 뒤에 다른 판정이 나오면 버튼이 사라집니다. 이미 적용한 결과는 되돌린 뒤 다시 굴립니다.
- 후발 행동 스킬은 예약되고 메인 페이즈 끝에 【속도】 순으로 실행됩니다. 지연 공격은 정해진 때에.

### 반응·추격·반격
- 맞는 쪽이 쓸 수 있는 수동 스킬(능동 회피·패링 등)은 **팝업**으로 묻습니다(시트 「자동」이면 바로 사용). 같은 대상을 여러 번 치는 공격은 첫 타에서 피하면 남은 타격도 빗나갑니다. 무작위 대상 다회 공격은 맞을 때마다 묻습니다.
- 추격·반격은 조건이 맞으면 자동, 선택형이면 팝업. 추격·반격의 연쇄는 일어나지 않습니다.

### 결과 카드와 자동 적용
- 공격·스킬·종료 페이즈 결과는 채팅 카드로 나옵니다. **자동 적용** 설정에 따라
  - 끔: GM이 카드의 [적용]을 누름 / 확인 후 적용 / 즉시 적용.
  - 전투 화면 GM 줄의 「자동 적용 켬/끔」으로 이 전투에서만 바꿀 수 있습니다(끌 때 지금까지 자동 적용된 것을 되돌릴지 묻습니다).
- 카드의 **[되돌리기]**로 적용을 취소합니다. 쓰러짐·[석화]가 되돌려지면 풀렸던 자세·대기·예약도 돌아옵니다.
- 자동화할 수 없는 스킬은 카드에 「GM 판단 필요」가 붙습니다.

### 종료 페이즈
- [독] 대미지 → 리젠 → (그리모어 유지비) → 자연 회복 → 강화·약화 턴 −1 → 심도 −1. 결과 카드 하나로 나옵니다.

### 끝
- 한쪽이 전멸하면 「종료 대기」. GM [전투 종료]에서 결과(승리·패배·도주 등)를 고릅니다.
- **승리** → 갈무리 카드: 에너미마다 드롭 2D6. 드롭 조작 스킬이 있으면 [−][+]로 고치고 [확정]. 풀의 아이템은 [가져가기]로 캐릭터를 골라 받습니다. GM [갈무리 종료]로 남은 것은 버립니다.
- 전투가 끝나면 [수면]·[스턴]·봉인만 풀리고, 다른 상태 이상과 오버히트는 남습니다(탐색 시간으로 회복).

## 9. 성장과 세션 마무리

- **세션 시작**(GM 스크린 마을): 각 캐릭터 【FP】를 설정값으로.
- **생활비**: 세션을 마칠 때 걷기.
- **세션 결과**: 목표 달성·던전 레벨·참가 여부·보너스로 경험점·돈을 나눕니다. 레벨업할 수 있게 되면 표시됩니다.
- **레벨업**: 플레이어가 시트 [레벨업]을 누릅니다. 레벨업 한 번에 한 스킬 +1(Lv1은 한 스킬 SL 2까지). 남은 SL을 다 찍기 전에는 다음 레벨업을 못 합니다(GM은 확인 후 가능).
- 플레이어는 레벨·경험점을 직접 고칠 수 없습니다(GM만).

## 10. 추가 컨텐츠

GM 스크린 「준비」 [추가 컨텐츠 등록]을 누르면 아이템 폴더 「추가 컨텐츠」에 들어갑니다. 등록한 월드는 이 폴더의 아이템이 상점에도 나오고(책·그리모어 제외), 능력치 편집 창에 「보전」 칸이 생깁니다. 다시 누르면 이미 있는 아이템의 효과·해설만 새 버전으로 바뀝니다(GM이 고친 가격은 그대로).

## 11. GM 도구 모음

- **상태 창**(파티 카드·에너미 카드의 심장 아이콘): 상태 이상·강화·약화를 직접 걸고 풉니다.
- **몬스터 도감**(토큰 도구 용 아이콘): 만난 종·식별·처치 수·얻은 DROP. 처치 수가 설정 기준 이상이면 자동 식별.
- **희소종**: 에너미(토큰) 시트의 [희소종으로]. 【HP】 배수·강화 항목을 고르면 그 토큰만 바뀝니다(받은 대미지 유지). ★ 표시는 GM에게만 보입니다.
- **에너미 랜덤 행동**: 에너미 차례에 [랜덤 행동]이 통상 공격·주행동 스킬과 대상을 무작위로 고릅니다.

## 13. 자주 묻는 것

- **스킬을 못 찍어요.** 스킬은 작성 중, 레벨업 직후, 길드 재분배·직업 변경 직후에만 찍을 수 있습니다. 스킬 트리 위쪽에 지금 열린 창구가 안내됩니다.
- **[상점] 버튼이 눌리지 않아요.** GM이 상점을 열어야 합니다(마을에 도착하면 자동으로 열림).
- **플레이어 메뉴가 사라졌어요(미궁).** GM이 처리하지 않은 이벤트가 있습니다. GM이 처리하면 다시 보입니다.
- **결과가 HP에 반영되지 않아요.** 자동 적용 설정이 「끔」 또는 「확인 후 적용」이면 카드의 [적용]을 눌러야 합니다.
- **다시 굴리기 버튼이 없어요.** 그 판정 뒤에 다른 판정이 나왔거나, 이미 반응(회피 등)을 썼거나, 반동처럼 행동 전체 대미지로 정해지는 스킬입니다.
- **에너미 정보가 ???예요.** 이번 전투에서 식별하지 못했습니다. GM이 식별 판정을 하거나, 해석 글라스를 쓰면 공개됩니다.
- **소리가 안 나요.** 브라우저는 페이지를 연 뒤 한 번 클릭해야 소리를 냅니다. 화면을 한 번 누르세요.
- **업데이트했는데 스킬 효과가 예전 같아요.** GM 스크린 위쪽 [효과 데이터 갱신]을 누릅니다.
