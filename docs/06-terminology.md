# 06. 한국어 표기 규칙

이 시스템의 모든 한국어 문자열(UI, 채팅 카드, 데이터)은 Notion 한국어판과 같은 표기를 쓴다. 기준은 `docs/glossary.json`이다.

## 1. glossary 사용법
- 새 문자열에 게임 용어가 들어가면 반드시 glossary의 `ko`를 쓴다. `forbidden`의 표기는 쓰지 않는다.
- glossary에 없는 용어가 필요하면 임의로 만들지 말고 `build/report.md`의 「용어 추가 필요」에 원어와 후보를 적어 사람에게 넘긴다.
- `source`의 뜻: `정식 한글판(게임 화면)`·`정식 한글판(공식 자료)` = 『세계수의 미궁 1·2·3 HD REMASTER』 공식 한국어판 표기. `자체 번역` = 이 번역판에서 정한 표기(비고에 기준이 적혀 있는 경우가 많다).

## 2. 괄호 기호 (이 게임 전용 표기 — 바꾸거나 빼지 않는다)
| 기호 | 쓰임 | 예 |
|---|---|---|
| 【 】 | 능력치·부능력치 | 【STR】 【물리 공격】 【억제 방어】 【HP】 【FP】 |
| 〈 〉 | 속성 | 〈참〉〈괴〉〈돌〉〈염〉〈빙〉〈뇌〉 |
| 《 》 | 스킬 이름 | 《검 마스터리》 《이 악물기》 |
| \[ \] | 상태 이상·봉인·전투 불능 | \[독\] \[맹목\] \[머리\] 봉인 \[전투 불능\] |
| 『 』 | 강화·약화 효과 이름 | 『물리 공격 상승: 3』 |
| ○ | 원문 ● 자리표시 | 『속성 부여: ○』 |

- UI에서도 같은 기호를 쓴다. 예: 시트의 부능력치 라벨 "【물리 명중】", 채팅 카드 "《힐링》 — 회복 8".
- 데이터 파일 안의 Notion 이스케이프(`\[`, `\~`)는 변환 시 제거하고 표시할 때는 기호 그대로.

## 3. 주요 확정 표기 (자주 틀리는 것)
- 속성 雷는 **〈뇌〉**(내성 표기 "뇌3", 『내성 부여: 뇌』). 일반 낱말 의뢰·무뢰한·천뢰는 그대로.
- 稲妻는 **벽력**(《벽력의 인술》), 雷는 번개(《번개의 인술》) — 둘을 섞지 않는다.
- 통화 단위 **G**. 숫자에 붙인다(100G). 조사는 '지' 발음 기준: "G를", "G와", "G로".
- 클래스 ショーグン은 **장군**. 무기 종류 突剣 **세검**, 鎚 **망치**.
- 鍛冶는 **제련**(대장간). 몸을 단련한다는 일반 낱말은 '단련'.
- 소재 牙는 **이빨**, 羽는 **날개·깃털**(새에게서 얻으면 깃털, 그 밖은 날개, 소재 종류를 통틀어 말할 때 날개·깃털).
- 食料는 **식료품**, 経験点은 **경험점**, R(ランク)은 **R(랭크)**.
- 로마 숫자는 영문자 **II, III**(메디카 II). 그리스 문자는 붙여 쓴다(테리아카α).
- 스킬 표 항목: 코스트, MaxSL, 타이밍, 사거리, 대상, 부위, 분류, 해설.

## 4. UI 문구
- 문체: 시트·버튼은 명사형("판정", "적용", "되돌리기"), 채팅 카드 설명은 원문 룰 문체(평서형 "~한다")와 맞춘다.
- 숫자와 단위: "3턴", "SL 2", "R3", "Lv5". 다이스는 "6D6", "2D6".
- 띄어쓰기는 glossary 표기를 그대로 따른다(예: 삼림개구리, 화염도마뱀 소환, 스노 드리프트).
