# 07. 미결 사항

원문에 명시가 없어 **임시 처리**를 정해 둔 항목이다. 구현은 임시 처리대로 하되, 해당 지점에 `// OPEN-QUESTION #n` 주석을 달고, 가능하면 GM이 바꿀 수 있는 설정으로 둔다.
확정되면 `01-rules.md` §9 표로 **번호 그대로** 옮기고 여기서 지운다(코드 주석의 `07 #n`도 `01 #n`으로 바꾼다). 새 항목 번호는 01·07을 통틀어 가장 큰 번호 + 1.

| # | 질문 | 임시 처리 |
|---|---|---|
| 26 | 공격 명중 판정에서 【FP】 주사위 추가·다시 굴리기 | 단계 4에서는 지원하지 않음(1로 【FP】 획득만). 스킬 사용 흐름(단계 6)에서 다시 정한다 |
| 168 | 추가 컨텐츠(사용자 하우스 룰, 원문 없음) | **일부 등록(v0.31.0)**, GM 스크린 「준비」 [추가 컨텐츠 등록] → 아이템 폴더 「추가 컨텐츠」(`data/defaults/expansion.json`). 자동: 마드라 I~IV(【TP】 5·10·15·전부 — 「메디카의 절반쯤」을 임시로 메디카 10·20·30·전부의 절반, 가격은 메디카와 같게). GM 처리(효과 데이터 없음 → 사용 시 「GM이 적용」 안내): 해부용 수용액, 해석 글라스, STR·TEC·VIT·AGI·LUC의 보전(가격 임시 5000G), 비전의 서(임시 5000G). **질문**: ① 마드라 회복량·가격 확정? 암리타(TP 10·20)와 겹치는데 둘 다 둘까? ② 해부용 수용액 「사용한 턴」은 라운드 기준(그 라운드에 쓰러진 모든 적)인가, 사용 이후 그 턴 끝까지인가? ③ 해석 글라스의 「이 전투 동안 전 정보 공개」를 플레이어 화면에도 보일까(지금 도감은 GM 설정 bestiaryPlayers)? ④ 보전은 GM 보너스 칸(abilities.bonus)에 +1로 둘까, 따로 「보전」 칸을 만들까? 상한(캐릭터당 몇 번)? ⑤ 비전의 서: 「무조건 스킬 획득」은 사용 즉시 스킬 트리를 열어 SL 1을 찍기 전엔 닫을 수 없게 할까? ⑥ XX의 기동부적: 속성 종류(염·빙·뇌만? 참·괴·돌도?), 대미지 식(알케미스트 술식처럼 【속성 공격】 + nD6?), 명중 판정 능력치, 봉인 시 사용 제한(팔·머리 봉인이면 불가?) ⑦ XX향: 억제 방어 목표치(고정 vs 랭크별), 부여할 상태 이상 종류, 심도 ⑧ XX의 책: 무기 슬롯 vs 장신구 슬롯(장신구면 「장착 중 통상 공격이 바뀐다」), 바뀐 통상 공격의 억제 공격 값 ⑨ 그리모어: 텅 빈 광석은 「처음 장착할 때 본인 스킬·SL 저장」인데 저장할 스킬은 하나(고르기)인가 전부인가, 기록한 스킬을 쓸 때 스테이터스 페널티(예: 모든 능력치 −1·HP 최대 −10%) 수치, 무기 조건 스킬은 그 무기 장비 필요(지금 규칙 그대로 가능), 방패 조건은 방패 장비 필요(서브 클래스 규칙과 같아 예외 없음) — 고유 스킬(★)은 기록 불가로 둔다 |
