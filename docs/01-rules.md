# 01. 룰 명세

구현 대상 룰을 공식 형태로 정리한 문서다. 각 절의 근거 파일을 `→`로 표시했다. 문장의 뉘앙스나 예외가 필요하면 근거 파일을 직접 읽는다.

공통 원칙
- **모든 나눗셈은 버림**(원문 FAQ 2). 음수 결과의 처리 등 명시가 없는 것은 07에 있다.
- 【속도】가 장비 보정 등으로 음수가 되면 **0으로 취급**(FAQ 3).
- 괄호 기호의 뜻: 【능력치·부능력치】 〈속성〉 《스킬》 \[상태 이상·봉인\] 『강화·약화 효과』. 자세한 건 06.

## 1. 능력치와 부능력치
→ `data/raw/character/캐릭터-작성-(Character-Generation).md`

### 1.1 능력치
- 5종: 【STR】【TEC】【VIT】【AGI】【LUC】.
- 작성 시 3D6을 5번 굴려 나온 값을 그대로 각 능력치에 배정(값 이동 금지) → 메인 클래스의 능력치 보정을 더한다.
- **능력치 보너스** `xB = floor(x / 5)`. 판정은 주로 이 값을 쓴다.

### 1.2 부능력치
| 부능력치 | 식 |
|---|---|
| 【HP】 최대 | `VIT_B×2 + Lv + 5` |
| 【TP】 최대 | `TEC_B + Lv + 3` |
| 【물리 명중】 | `floor((STR_B + AGI_B) / 2)` |
| 【속성 명중】 | `floor((TEC_B + LUC_B) / 2)` |
| 【회피】 | `floor((AGI_B + LUC_B) / 2) + 5` |
| 【물리 공격】 | `STR_B + 무기의 물리 공격` |
| 【속성 공격】 | `TEC_B + 무기의 속성 공격` |
| 【방어】 | `방어구의 방어` |
| 【억제 공격】 | `floor((TEC_B + LUC_B) / 2)` |
| 【억제 방어】 | `floor((VIT_B + LUC_B) / 2)` |
| 【속도】 | `AGI`(원값) + 장비 속도 |

여기에 장비 보정(무기의 명중·속도, 방어구의 회피·속도, 장식, 제련 효과), 상시 스킬, 강화·약화 효과, 상태 이상·봉인 보정을 더한다.

- **내성**: 〈참〉〈괴〉〈돌〉〈염〉〈빙〉〈뇌〉 6종. PC는 GM 지시가 없으면 전부 3.
- **아이템 소지 한도**: `STR_B + VIT_B + 3`(장비 중인 것 제외, 장비 안 한 무기·방어구는 포함). 백팩 등으로 늘어난다.
- **FP**: 세션 시작 시 1.

## 2. 일반 행위 판정
→ `data/raw/rules/일반-행위-판정.md`, `data/raw/misc/FAQ.md`

- `2D6 + 해당 능력치 보너스(또는 지정된 수정치)` = **달성값**. 달성값 ≥ **목표값**이면 성공.
- 능력치별 용도: STR(힘쓰기), TEC(지식·감정·두뇌), VIT(독·병·구속 버티기), AGI(달리기·전신 운동·은밀), LUC(위험 감지·물건 찾기·손재주).
- 목표값 기준: 7 쉬움 / 10 / 13 / 16 / 20 / 25 / 30.
- **대항 판정**: 동점이면 더 **수동적인 쪽**이 이긴다. 양쪽 절대 성공이어도 수동 측 승리. 능동·수동을 정하기 어려우면 GM 재량으로 재판정(사용한 아이템·스킬 효과 유지).
- **절대 성공**: 주사위 눈에 6이 여러 개 → 목표값과 무관하게 성공. (여럿이 성공도를 겨룰 때는 수동 측의 절대 성공 우선.)
- **절대 실패**: 굴린 주사위가 모두 1 → 무조건 실패.
- 절대 성공·실패는 "확실한 성공·실패"일 뿐 결정적 성공·치명적 실패가 아니다(GM 지시가 없는 한).
- **FP 획득**: 일반 행위 판정에서 눈 1이 하나 나올 때마다 FP +1.
- **FP 사용**
  - 주사위 추가: FP 1당 1D6 추가, 굴린 것 중 **2개를 골라** 쓴다. 이 판정에서는 1이 나와도 FP를 얻지 않는다.
  - 다시 굴리기: 판정당 1회. 재굴림 전후 모두 FP 획득 없음. 앞서 늘린 주사위 개수는 유지된다(FAQ 4).
  - FP 코스트 스킬: 스킬 설명대로.
- 드롭 판정·채집 판정 등 **일반 행위 판정이 아닌 굴림은 1이 나와도 FP를 얻지 않는다**(FAQ 5).

## 3. 전투
→ `data/raw/rules/전투-룰.md`

### 3.1 식별
- 전투 처리 전에, 아무것도 소모하지 않고 1회. PC 중 누군가 【TEC】 판정, 목표값 = 에너미 【희소도】. 한 번의 판정으로 전투에 나온 에너미 전체에 적용.
- 성공: GM이 Lv·내성·주요 스킬 등을 공개.
- PC 전원 실패: 그 에너미의 내성을 **최소 3**으로 취급하고 《약점: ○○》 스킬을 적용하지 않는다.
- 희소종 간파는 【희소도】+2 이상의 달성값 필요(그 미만이면 원래 데이터만 공개).

### 3.2 구조
- 최대 6 대 6. PC는 전위·후위 각 3명까지(에너미는 제한 없음).
- 한 진영이 전멸(또는 항복)·도주 성공할 때까지 반복: **개막 페이즈 → 메인 페이즈 → 종료 페이즈**.
- **기습**: 기습당한 쪽은 첫 턴에 수동 행동만 가능.

### 3.3 개막 페이즈 (전원 동시에 1행동)
배치 변경(자기 자신만, 전후위 이동·가로 순서) / 무기 교체(무기↔기타 슬롯의 무기) / 타이밍 「개막」 스킬 / 방어 전념(턴 끝까지 대기 상태, 받는 대미지 절반) / 도주.

### 3.4 메인 페이즈
- 행동 순서: **최속 행동** → 【속도】 내림차순 → **후발 행동**. 동률이면 PC → 아군 NPC → 에너미.
- 행동(하나): 통상 공격(장비 무기, 무기의 기본 속성) / 타이밍 「주행동」 스킬 / 아이템 사용.
- **스킬 발동 판정**: 「주행동」 스킬은 명중 판정이 없어도 2D6을 굴린다. **1이 2개(1쌍)면 발동 실패**. 1이 나오면 FP 획득.
- **대기 상태**: 메인 페이즈의 순서 행동을 포기하고 이로운 효과를 얻는 상태. 원칙적으로 그 턴 종료 페이즈에 해제. 해제되는 순간 그 턴의 메인 행동을 마친 것으로 본다.

### 3.5 공격 롤
1. **사거리**: 「근」은 자신이 아군 전위이고 대상이 적 전위일 때만. 「원」은 위치 무관.
2. **명중**: 물리면 【물리 명중】, 속성이면 【속성 명중】으로 대상 【회피】를 목표값으로 일반 행위 판정. 여러 대상·여러 회 공격이면 **대상·회차마다** 판정.
3. **내성**: 공격 속성의 내성. 복합 속성은 관련 속성 중 **최저값**. **무속성은 항상 0**.
4. **대미지 다이스 수**: 물리 `【물리 공격】 − 대상 【방어】`, 속성 `【속성 공격】`, 여기에 스킬 보정.
5. 그 수만큼 D6을 굴려 **내성보다 큰 눈의 개수 = 실대미지**(HP 감소량).
6. **크리티컬 히트**: 대미지 다이스에서 (6의 개수 − 1의 개수) ≥ 2 → 대미지 다이스 4개 추가 + "크리티컬 시" 스킬 발동. 『크리티컬 업』이면 ≥ 1.
7. 대기 상태의 방어 전념 등 "대미지 절반"은 실대미지에 적용(버림).
- **수동 행동**: 공격 롤 1회에 대해, 공격 대상은 1번만 타이밍 「수동」 스킬로 반응할 수 있다.
- **다회·범위 공격**: 명중·억제 공격 판정은 대상 1체씩. 1로 FP를 얻는 것은 **주행동 1회당 처음 한 번뿐**.
- **무작위 대상**: 사거리 안의 적 중 균등 확률. 「같은 에너미는 1번만」 지정이면 중복으로 뽑힌 공격은 없었던 것으로.

### 3.6 회복 롤
- 2D6 발동 판정(1쌍이면 실패, 1이면 FP)만 굴리고 명중 판정은 없다.
- `【속성 공격】 + 스킬 보정` 개의 D6 중 **4 이상인 눈의 개수 = HP 회복량**.

### 3.7 억제 방어 롤 (상태 이상·봉인 저항과 자연 회복)
- `2D6 + 【억제 방어】` vs 목표값. 성공하면 악영향을 막는다(또는 자연 회복).
- 부여 방식은 스킬마다 두 가지다.
  - **고정 목표값**: 예 "목표값 (공격자의 【억제 공격】+(7+SL))의 억제 방어 롤, 실패하면 \[마비\]".
  - **대결 판정**: 예 "자신의 【억제 공격】과 대상의 【억제 방어】로 대결 판정을 하고, 승리하면 …"(주로 에너미 스킬).
- 부여에 성공하면 그 **저항 목표값을 심도로 기록**한다(\[석화\]\[스턴\] 제외).

### 3.8 상태 이상
| 이름 | 효과 |
|---|---|
| \[석화\] | 모든 행동 불가, 【회피】 0. 심도 없음 |
| \[저주\] | 공격 롤로 적에게 준 실대미지의 절반이 자신에게 돌아온다(방어·내성 무시) |
| \[독\] | 종료 페이즈에 실대미지 = **독을 건 자의 【억제 공격】 값**(부여 시의 달성값이 아님) |
| \[수면\] | 모든 행동 불가, 【회피】 0, 〈참〉〈괴〉〈돌〉 내성 −1로 취급. 공격 롤을 받으면 그 처리 직후 해제 |
| \[혼란\] | 부여 순간과 매 턴 개막 페이즈에 1D6, 1~3이면 그 턴 개막 행동 불가 + 메인에서 자신 제외 같은 열 아군 중 무작위에게 통상 공격(수동 스킬은 가능) |
| \[마비\] | 부여 순간과 매 턴 개막에 1D6, 1~3이면 그 턴 모든 행동 불가(대기 취소), 그 턴 【회피】 0 |
| \[공포\] | \[마비\]와 같은 처리 |
| \[맹목\] | 【물리 명중】【속성 명중】【회피】 −3 |
| \[스턴\] | 그 턴 행동권 상실(대기 취소), 【회피】 0, 반드시 그 턴에 끝남. 심도 없음 |

### 3.9 봉인 (심도 기록)
| 이름 | 효과 |
|---|---|
| \[머리\] 봉인 | 부위 「머리」 스킬 사용 불가, 【물리 명중】【속성 명중】 −2 |
| \[팔\] 봉인 | 부위 「팔」 스킬 사용 불가, 【물리 공격】 −4 |
| \[다리\] 봉인 | 부위 「다리」 스킬 사용 불가, 【회피】 0, 도주 판정 참가 불가 |

### 3.10 강화 효과·약화 효과
- 지속은 턴 수로 관리하고 **종료 페이즈에 일괄 −1**, 0이 되면 소멸.
- 강화·약화 각각 **3종류까지** 동시 적용. 같은 종류를 겹치면 **가장 큰 효과만** 적용.
- **대항** 관계인 효과가 같은 캐릭터에 걸리면 **둘 다 소멸**.

| 이름 | 분류 | 대항 | 효과 |
|---|---|---|---|
| 속성 부여: ○ | 강화 | — | ○(염·빙·뇌)를 공격의 기본 속성에 추가 |
| 내성 부여: ○ | 강화 | 약점 부여: ○ | ○ 내성 +1 |
| 물리 공격 상승: ○ | 강화 | 물리 공격 저하 | 【물리 공격】 +○ |
| 속성 공격 상승: ○ | 강화 | 속성 공격 저하 | 【속성 공격】 +○ |
| 방어 상승: ○ | 강화 | 방어 저하 | 【방어】 +○ |
| 속도 상승: ○ | 강화 | 속도 저하 | 【속도】 +○ |
| 명중 상승: ○ | 강화 | 명중 저하 | 【물리 명중】【속성 명중】 +○ |
| 회피 상승: ○ | 강화 | 회피 저하 | 【회피】 +○ |
| 억제 방어 상승: ○ | 강화 | 억제 방어 저하 | 【억제 방어】 +○ |
| 최대 HP 강화: ○ | 강화 | — | 【HP】 최대 +○ |
| HP 리젠: ○ / TP 리젠: ○ | 강화 | — | 종료 페이즈에 ○ 회복 |
| 추격: ○ | 강화 | — | ○에 해당하는 캐릭터가 공격 롤을 하면 추격 |
| 크리티컬 업 | 강화 | — | 크리티컬 조건이 차이 ≥ 1로 완화 |
| ○ 저하: ○ | 약화 | 대응 상승 | 해당 값 −○ |
| 약점 부여: ○ | 약화 | 내성 부여: ○ | ○ 내성 −1 |

glossary에는 위 표 밖의 이름(공격 상승, 물리 명중 상승, 물리 방어 상승, 억제 공격 상승, 완전 내성 등)도 있다. 스킬·에너미 데이터에서 쓰이므로 같은 방식으로 등록한다(강화/약화 분류와 대항 관계는 07에서 확정).

### 3.11 추격·반격·지연·연계·토큰·오버히트
- **추격·반격**: 특별한 지시가 없으면 통상 공격의 물리 공격 롤. 추격의 추격·반격의 추격·반격의 반격은 없다. **추격에 대한 반격은 있다**.
- **지연 공격**: 스킬에 적힌 턴 수가 지난 그 턴의 종료 페이즈에 공격 롤. 실행 전까지 새 지연 공격 스킬 사용 불가.
- **연계 공격**(에너미): 연계자 전원 필요, 가장 느린 【속도】에 맞춰 동시 행동, 참가자 전원 그 턴 행동 종료.
- **토큰**: HP·TP 없는 자율 유사 NPC. 배치자와 같은 【속도】로 정해진 행동만 반복하고 배치된 턴에도 행동. 배치자가 전투 불능이면 소멸.
- **오버히트**(임페리얼): 《○○ 드라이브》 사용 후 정해진 턴 동안 드라이브 스킬 사용 불가. 캠프로 완전 회복. 랜덤 던전은 1턴, 베이직 던전은 1세그먼트마다 1 회복.

### 3.12 종료 페이즈 (순서 고정)
1. 이 턴에 발동할 지연 공격의 공격 롤
2. \[독\] 대미지
3. "종료 페이즈에 ~" 효과(리젠 포함)
4. \[석화\]\[스턴\]을 제외한 상태 이상·봉인의 자연 회복: 각각 심도를 목표값으로 억제 방어 롤, 성공하면 소멸
5. 강화·약화 남은 턴 −1, 0이면 소멸
6. \[석화\]\[스턴\]을 제외한 남은 상태 이상·봉인의 심도 −1

### 3.13 전투 불능·종료·도주
- 【HP】 ≤ 0 → \[전투 불능\], 모든 행동 불가.
- 전위가 전원 전투 불능이면 그 진영의 전위·후위가 자동으로 교대한다.
- 한 진영이 전원 \[전투 불능\] 또는 \[석화\]면 전멸.
- 에너미 전멸 시 **드롭 판정**: 쓰러뜨린 에너미 1체마다 2D6 → 에너미 DROP 표 참조(FP 획득 없음).
- **도주**: 개막 페이즈에 파티 전원이 선언 → 즉시 참가자 전원이 【회피】로 판정, 도주 측 최고 달성값 > 추격 측 최고 달성값이면 성공(동점 실패). 도주 성공 시 드롭 없음.

### 3.14 희소종
- 【HP】 2~3배, 내성 0→1, 1→2.
- GM 재량으로 【물리 명중】【속성 명중】【회피】 +1, 【물리 공격】【속성 공격】【방어】 +2까지.

## 4. 던전 탐색
→ `data/raw/rules/던전-탐색-룰.md`, `베이직-던전.md`, `랜덤-던전.md`

- **던전 레벨** 1~15. 에너미 레벨·소재 R의 기준.
- **채집 이벤트**(벌채·채굴·채취): 파티 대표가 방법을 선언한다.
  | 방법 | 채집 개수 | 아앗! 값 |
  |---|---|---|
  | 조금만 | 1 | 3 |
  | 적당히 | 2 | 4 |
  | 잔뜩 | 3 | 5 |
  - 《벌채》《채굴》《채취》 중 해당하는 것과 《수확 마스터》 등의 파티 합계 SL만큼 채집 개수 증가.
  - 채집 개수만큼 2D6 → 던전별 결과표. 눈이 **아앗! 값 이하**면 (던전 레벨+1) 에너미에게 기습(소재는 얻음). FP 획득 없음.
- **트랩**: 보통 HP 대미지 = 던전 레벨×3, TP 대미지 = 던전 레벨×2.
- **F.O.E.**: 던전 레벨 +2~+3. 조우 시 바로 전투가 아니라 'F.O.E. 조우 상태'(회피 방법을 선언하고 GM이 판정을 지시).
- **캠프**: 최소 6시간(베이직 던전에선 세그먼트). `(경과 시간)+(Lv)`만큼 HP·TP 회복, \[전투 불능\]도 회복, 임페리얼 오버히트 완전 회복. **'식료품' 분류 아이템 1개 소모**. 습격 판정: 주변 위험도 3~6, 2D6이 그 이하면 기습 전투(회복 없음). 텐트는 위험도 −1.
- **랜덤 던전**: 1시간 = 1턴, 깊이만큼 랜덤 이벤트(2D6 표)를 순서대로. 채집표 포함. 표 전체는 근거 파일.
- **베이직 던전**: 1세그먼트 단위로 이동·채집·조사·캠프. F.O.E.는 고정 루틴으로 이동하고, 같은 칸이나 같은 통로에서 만나면 조우.
- 낮 06:00~17:59, 밤 18:00~05:59(주행성·야행성 스킬에 쓰인다).

## 6. 캐릭터 작성
→ `data/raw/character/캐릭터-작성-(Character-Generation).md`

1. 3D6×5 → 능력치에 배정(값 이동 불가).
2. 메인 클래스: 능력치 보정 적용, 습득 가능 스킬 결정.
3. 서브클래스(선택): 무기·방패만 서브 클래스 것도 장비 가능(갑옷 불가). 서브 스킬 습득 가능(MaxSL의 서브 값까지, `-`면 불가). 서브클래스를 고르면 **고유 스킬(★) 습득 불가**. 능력치 영향 없음.
   - 메인·서브에 같은 이름의 스킬이 있으면 메인 쪽만 유효(SL 합산 불가). 같은 이름은 같은 스킬로 취급하므로 전제 조건은 서로 충족시킨다.
4. 스킬: 합계 SL 5, Lv1은 한 스킬 최대 SL 2, 전제 조건 충족. 서브클래스가 없으면 고유 스킬(★)을 추가로 무료 습득.
5. 커먼 스킬 1개.
6. 아이템 구입. **초기 소지금 = (100 − 3D6×5회 합계) × 10G**. 작성 시에는 소재 없이 G만으로 구입·제련 가능.
7. 부능력치 계산. 8. 내성 전부 3. 9. 퍼스낼리티(경력표 D666, 선택).

## 7. 장비·쇼핑·제련
→ `data/raw/data/무기·방어구.md`, `아이템.md`, `소재.md`, `data/raw/rules/쇼핑과-생활.md`

- **슬롯**: 『무기』『갑옷』『기타』. 기타 = 무기(서브웨펀)·방패·장식 중 하나.
  - 무기·방패는 메인 또는 서브 클래스에서 쓸 수 있는 것, 갑옷은 메인 클래스 것만.
  - 서브웨펀은 전용 스킬이 없으면 동시 사용 불가(교체용).
- **무기·방어구의 R(랭크)** 1~15. 성능과 가격이 R의 식으로 정해진다. 예: 검 물리 공격 `(R×3)+5`, 가격 `(R의 제곱)×100`. 주먹은 R 대신 Lv 기준.
  - 구입하려면 그 장비의 '대응 소재' 중 하나를 **R 이상**으로 1개 소모 + 가격 지불.
- **제련(대장간)**: 무기·방어구 하나당 2항목까지, 같은 효과 중복 불가. 대응 소재(R 이상) 1개 + 효과별 가격.
- **매각**: 구입가의 50%. 소재는 `(R의 제곱)×50G`.
- **생활비**: 레벨×10G(GM이 요구할 때).
- **소모품**: 전투 중에는 메인 페이즈 행동으로 사용, 사용하면 소멸. 기타 아이템은 소모품이라고 적혀 있지 않으면 반복 사용.
- 통화 단위는 **G**.
