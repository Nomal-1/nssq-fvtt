# 07. 미결 사항

원문에 명시가 없어 **임시 처리**를 정해 둔 항목이다. 구현은 임시 처리대로 하되, 해당 지점에 `// OPEN-QUESTION #n` 주석을 달고, 가능하면 GM이 바꿀 수 있는 설정으로 둔다. 확정되면 01에 반영하고 여기서 지운다.
