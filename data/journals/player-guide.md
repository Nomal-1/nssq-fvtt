# 시작하며
이 저널은 플레이어를 위한 **간결한 룰북**입니다. 규칙의 핵심과 이 Foundry 시스템에서의 조작법만 짧게 모았습니다.
자세한 규칙은 컴펜디움 「룰북(전문)」을 보세요.

- 표기: 【능력치·부능력치】, 《스킬》, [상태 이상], 『분류·강화/약화』, 〈속성〉.
- **모든 나눗셈은 버림**입니다.
- 계산·판정·적용은 시스템이 합니다. 여러분은 무엇을 할지 고르고 버튼을 누르면 됩니다.

# 판정
- 판정 = **2D6 + 능력치 보너스(B)**. 이 합이 **달성값**이고, **목표값** 이상이면 성공.
  - 능력치 보너스 = 능력치 ÷ 5(버림).
- 목표값 기준: 7 쉬움 / 10 / 13 / 16 / 20 / 25 / 30.

| 능력치 | 쓰는 곳 |
|---|---|
| 【STR】 | 힘쓰는 일 |
| 【TEC】 | 지식·감정·두뇌 노동 |
| 【VIT】 | 독·병·구속 버티기 |
| 【AGI】 | 달리기·전신 운동·은밀 행동 |
| 【LUC】 | 위험 감지·물건 찾기·손재주 |

- **절대 성공**: 6이 두 개 이상 → 무조건 성공. **절대 실패**: 굴린 눈이 모두 1 → 무조건 실패.
- **대항 판정**: 동점이면 수동적인 쪽이 이깁니다.
- **【FP】**: 일반 행위 판정에서 1이 나올 때마다 +1(드롭·채집 굴림은 제외). 세션 시작에 1.
  - 주사위 추가: 【FP】 1당 1D6을 더 굴리고 그중 2개를 고릅니다(그 판정은 【FP】를 얻지 않음).
  - 다시 굴리기: 판정당 1번(얻지 않음).
- 이 시스템에서는: 시트의 능력치를 누르면 판정 창이 열리고, GM이 [판정 요청]을 보내면 팝업이 뜹니다. 굴리기 전에 「2D6+11 → 20 이상이면 성공!」처럼 안내가 보입니다.

# 캐릭터
| 부능력치 | 식 |
|---|---|
| 【HP】 최대 | VIT B×2 + Lv + 5 |
| 【TP】 최대 | TEC B + Lv + 3 |
| 【물리 명중】 | (STR B + AGI B) ÷ 2 |
| 【속성 명중】 | (TEC B + LUC B) ÷ 2 |
| 【회피】 | (AGI B + LUC B) ÷ 2 + 5 |
| 【물리 공격】 | STR B + 무기의 물리 공격 |
| 【속성 공격】 | TEC B + 무기의 속성 공격 |
| 【방어】 | 방어구의 방어 |
| 【억제 공격】 | (TEC B + LUC B) ÷ 2 |
| 【억제 방어】 | (VIT B + LUC B) ÷ 2 |
| 【속도】 | AGI + 장비 속도 |

- 내성은 〈참〉〈괴〉〈돌〉〈염〉〈빙〉〈뇌〉 6종, PC는 모두 3.
- 소지 한도 = STR B + VIT B + 3(장비 중인 것은 세지 않음).
- 슬롯: 『무기』『갑옷』『기타』(기타 = 서브웨펀·방패·장식 중 하나).

## 만들기(작성 마법사)
액터 탭 [캐릭터 작성]을 누르면 GM이 대신 만들어 주고 마법사가 열립니다.
1. 3D6을 다섯 번 굴려 나온 순서대로 능력치에 배정.
2. 메인 클래스(능력치 보정), 서브 클래스(선택, 고르면 ★ 고유 스킬 없음).
3. 스킬: 합계 **SL 5**(Lv1은 한 스킬 SL 2까지). 커먼 스킬은 이와 따로 하나를 SL 1.
4. 장비: 작성 모드 상점(소재 없이 G만). 초기 소지금 = (100 − 3D6 다섯 번 합) × 10G.
5. 경력(선택) → 확인.

# 전투
한 턴 = **개막 페이즈 → 메인 페이즈 → 종료 페이즈**. 전위·후위 각 3명까지.

## 개막 페이즈(모두 동시에 하나)
방어 전념(그 턴 받는 대미지 절반) · 배치 변경 · 무기 교체 · 「개막」 스킬 · 도주.

## 메인 페이즈
- 순서: 최속 행동 → 【속도】 높은 순 → 후발 행동.
- 행동 하나: **통상 공격** / 「주행동」 스킬 / 아이템.
- 「주행동」 스킬은 2D6 발동 판정을 하고, **1이 두 개면 발동 실패**.

## 공격 롤
1. 사거리: 「근」은 내가 전위이고 대상이 적 전위일 때만. 「원」은 어디든.
2. 명중: 【물리 명중】 또는 【속성 명중】 판정, 목표값 = 대상 【회피】.
3. 대미지 다이스 수: 물리 = 【물리 공격】 − 대상 【방어】, 속성 = 【속성 공격】(+스킬 보정).
4. 다이스 중 **내성보다 큰 눈의 개수 = 대미지**.
5. **크리티컬**: 다이스의 (6의 개수 − 1의 개수) ≥ 2 → 다이스 4개 추가.
- 회복 롤: 【속성 공격】+보정 개의 D6 중 4 이상인 눈의 개수만큼 회복.
- 공격 하나에 대상은 「수동」 스킬로 한 번 반응할 수 있습니다.

## 종료 페이즈
[독] 대미지 → 리젠 → 상태 이상·봉인 자연 회복(억제 방어 롤, 목표값 = 심도) → 강화·약화 턴 −1 → 심도 −1.

## 끝
- 【HP】 0 이하 = [전투 불능]. 한쪽이 모두 쓰러지거나 [석화]면 끝.
- 승리하면 쓰러뜨린 적마다 드롭 2D6 → 갈무리.
- 도주: 개막에 전원 선언 → 【회피】 판정, 도주 측 최고값이 더 높으면 성공(드롭 없음).

# 상태 이상·강화
| 상태 이상 | 효과 |
|---|---|
| [독] | 종료 페이즈마다 건 자의 【억제 공격】만큼 대미지 |
| [마비]·[공포] | 개막에 1D6, 1~3이면 그 턴 행동 불가·【회피】 0 |
| [혼란] | 개막에 1D6, 1~3이면 같은 열 아군을 통상 공격 |
| [수면] | 행동 불가·【회피】 0, 공격을 받으면 깸 |
| [맹목] | 명중·【회피】 −3 |
| [저주] | 내가 준 대미지의 절반이 나에게 |
| [석화] | 행동 불가·【회피】 0, 자연 회복 없음 |
| [스턴] | 그 턴 행동 불가, 그 턴에 끝남 |

| 봉인 | 효과 |
|---|---|
| [머리] 봉인 | 「머리」 스킬 불가, 명중 −2 |
| [팔] 봉인 | 「팔」 스킬 불가, 【물리 공격】 −4 |
| [다리] 봉인 | 「다리」 스킬 불가, 【회피】 0, 도주 불가 |

- 상태 이상은 억제 방어 롤(2D6 + 【억제 방어】)로 막습니다. 걸리면 그 목표값이 **심도**가 됩니다.
- 전투가 끝나면 [수면]·[스턴]·봉인만 풀립니다. 나머지는 탐색 시간 1시간마다 자연 회복을 굴립니다.
- 강화·약화는 각각 3종류까지, 같은 종류는 가장 큰 것만, 대항하는 것끼리는 둘 다 사라집니다.

# 탐색·마을·성장
- **마을**: 도착하면 【HP】【TP】 최대·상태 이상 해제. 상점(구입·매각·제련), 길드(스킬 재분배·직업 변경, 경험점 소모·Lv1로), 파티 편성.
- **미궁**: 화면 위 메뉴로 이동·조사·채집·캠프·지도 작성을 제안하면 GM이 확인합니다. 채집은 많이 할수록 「아앗!」(기습) 위험이 커집니다.
- **캠프**: 시간만큼 회복, 식료품 1개 소모. 습격 판정이 있습니다.
- **경험점**: 끝까지 참가 5 + 목적 달성 5 + (던전 레벨 − 내 Lv)×2 + GM 보너스.
- **레벨업**: 시트 [레벨업]. 능력치에 메인 클래스 보정이 더해지고, 한 번에 한 스킬 +1(합계 SL 3).
- 누적 경험점이 10의 배수가 될 때마다 1D6으로 능력치 하나 +1.
- 스킬은 작성 중·레벨업 직후·길드 재분배 직후에만 찍을 수 있습니다.

# 전투 화면 조작
- 내 차례에 가운데 버튼: **[공격]**(빛나는 적 카드를 누름) / **[스킬]** / **[아이템]** / **[턴 종료]**.
  - 목록에서 고르면 위쪽에 해설·대상·코스트가 나오고, 못 쓰면 이유가 보입니다.
  - 스킬 앞의 두 아이콘은 [의존 부위][의존 무기]. 그 부위가 봉인되면 빨간 사선.
- 개막에는 내 줄의 [방어]·[배치]·[교체]·[스킬]·[행동 안 함] 중 하나.
- **【FP】 주사위**: 내 카드의 FP 칸을 눌러 「+n」 → 다음 공격의 명중 판정마다 n개 추가.
- **다시 굴리기**: 결과 카드 명중 줄의 [【FP】로 다시 굴리기](다른 판정이 나오기 전까지).
- 맞을 때 쓸 수 있는 회피·패링 스킬은 **팝업**으로 묻습니다. 시트 스킬 탭의 「자동」을 켜면 묻지 않고 씁니다.
- 카드를 누르면 지금 걸린 상태와 (식별했다면) 적의 정보가 보입니다.
- 결과는 채팅 카드로 나오고, GM 설정에 따라 바로 또는 GM 확인 뒤 적용됩니다.
