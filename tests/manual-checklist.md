# Foundry 수동 확인 절차

Foundry VTT **v12.331**에서 확인한다. 단계마다 갱신한다.

## 단계 0 — 뼈대
- [ ] `npm run link` 후 Foundry 시작 → 게임 시스템 목록에 「SRS가 아닌 세계수의 미궁 TRPG」가 보인다
- [ ] 이 시스템으로 월드를 만들고 들어간다. 콘솔(F12)에 `nssq` 관련 오류가 없다
- [ ] 액터 만들기: 캐릭터·에너미·토큰이 모두 목록에 한국어 이름으로 나오고, 만들고 열 수 있다
- [ ] 캐릭터 시트: 【STR】 등을 고치면 능력치 보너스·부능력치·【HP】/【TP】 최대가 즉시 바뀐다
- [ ] 아이템 만들기: 클래스·스킬·무기·방어구·장식·소모품·기타 아이템·소재 8종을 모두 만들고 열 수 있다
- [ ] 아이템을 캐릭터 시트에 끌어 놓으면 「아이템」 탭에 나오고 편집·삭제가 된다
- [ ] 해설(서식 텍스트) 편집·저장이 된다
- [ ] 게임 설정 → 시스템 설정에 「자동 적용」「세션 시작 【FP】」가 있다
- [ ] 토큰 바에 【HP】·【TP】가 기본으로 잡힌다

## 단계 1 — 컴펜디움
- [ ] 컴펜디움 탭에 「NSSQ」 폴더와 클래스·스킬·장비·아이템·소재·에너미 팩 5개가 보인다
- [ ] 스킬 팩: 클래스별 폴더 32개(커먼 포함), 합계 755개. 《검 마스터리》를 열면 타이밍·MaxSL 등이 채워져 있다
- [ ] 에너미 팩: Lv1/Lv2/Lv3~4/F.O.E. 폴더, 합계 65. 「숲쥐」를 월드로 가져오면 HP 5, 내성, 스킬 1개가 있다
- [ ] 장비 팩의 무기·방어구·장식, 아이템 팩의 소모품·기타 아이템·소재를 월드로 가져와 시트를 열 수 있다
- [ ] 클래스 아이템을 열면 해설이 보인다

## 단계 2 — 판정

### 능력치 표·클래스
- [ ] 기존 캐릭터의 능력치가 「굴림」 열로 옮겨져 있다(값이 사라지지 않음)
- [ ] 능력치 편집 창: 굴림·클래스·성장·GM 보너스·장비·최종·B 열. 「굴림」「성장」(GM은 「GM 보너스」도)은 입력 칸, 나머지는 자동 계산 (v0.7.0부터 「일시」 없음)
- [ ] 클래스 팩의 클래스를 시트에 끌어 놓으면 메인 클래스가 되고, 「클래스」 열에 보정 × Lv가 나온다. 두 번째는 서브 클래스, 세 번째·같은 클래스는 거부된다
- [ ] 위쪽 메인/서브 선택 상자로 바꾸면 「클래스」 열이 새 메인 클래스 보정으로 바뀐다
- [ ] Lv를 올리면 「클래스」 열과 최종값·B·【HP】·【TP】 최대가 함께 바뀐다
- [ ] 「성장」 열에 값을 넣으면 최종값·B가 바뀐다

### 능력치 굴리기(편의 기능)
- [ ] 「능력치」 제목 옆 [능력치 굴리기]를 누르면 3D6 5회 결과가 순서대로 채팅에 올라가고(합계·초기 소지금 포함) 배정 창이 뜬다
- [ ] 배정 창: [순서대로]는 1~5번째 값을 【STR】【TEC】【VIT】【AGI】【LUC】 순으로, [랜덤 배치]는 무작위로 넣는다. 각 칸에서 직접 고를 수도 있다
- [ ] 같은 값을 두 칸에 고르면 빨간 표시와 함께 [적용]이 비활성된다
- [ ] [적용]하면 「굴림」 열만 바뀌고, 【HP】·【TP】는 클래스 보정까지 포함한 최대값으로 채워진다. 체크했다면 소지금이 (100 − 합계) × 10G가 된다
- [ ] 배정 창을 닫아도 채팅 카드의 [배정하기]로 다시 열 수 있다(굴린 본인·GM만)

### 일반 행위 판정
- [ ] 능력치 표 「최종」 칸을 클릭하면 판정 대화창(능력치·수정치·목표값·【FP】 추가 주사위)이 뜬다. Shift+클릭은 대화창 없이 바로 굴린다
- [ ] 달성값 = 2D6 + B + 수정치. 목표값을 넣으면 성공/실패가 표시된다
- [ ] [6, 6]은 목표값과 관계없이 절대 성공, [1, 1]은 절대 실패로 표시된다

### 【FP】 획득과 다시 굴리기
- [ ] 【FP】가 1 이상일 때 1이 나오면 「【FP】 +n (확정 시 지급)」과 [확정] [다시 굴리기]가 나온다. 이때 캐릭터의 【FP】는 아직 그대로다
- [ ] [확정]을 누르면 【FP】가 n 오르고 두 버튼이 사라진다
- [ ] 확정하지 않고 같은 캐릭터로 다음 판정을 굴리면 이전 판정이 자동 확정되어 【FP】가 들어온다
- [ ] 【FP】 0에서 [1, 3]이 나오면 바로 【FP】 +1이 되고 버튼이 없다(다시 굴릴 수 없으므로)
- [ ] [다시 굴리기]: 【FP】 1 소모, 보류 중이던 【FP】는 들어오지 않는다. 다시 굴린 뒤의 1도 【FP】를 주지 않는다. 한 번 쓰면 버튼이 사라진다

### 【FP】로 주사위 추가(판정 전에만)
- [ ] 주사위 추가는 판정 대화창의 「【FP】로 추가할 주사위」 칸에서만 정한다. 이미 굴린 카드에는 추가 버튼이 없다
- [ ] 2개를 추가해 굴리면 【FP】가 2 줄고 4D6이 굴려지며, 높은 2개가 사용된다(나머지는 흐리게)
- [ ] 이 판정에서는 1이 나와도 【FP】를 얻지 않는다([확정] 버튼도 나오지 않는다)
- [ ] 흐린 주사위를 누르면 사용할 2개가 바뀌고 달성값이 다시 계산된다(굴린 본인·GM만)
- [ ] 이 판정을 [다시 굴리기]하면 4D6 그대로 다시 굴린다(FAQ 4)

### 대항 판정
- [ ] 다른 플레이어가 카드의 [대항 판정]을 누르면 대화창에 「(먼저 굴린 쪽)의 달성값 N이 목표값」 안내가 나온다
- [ ] 양쪽 카드에 「달성값 / 목표값 N(상대의 달성값) → 승자」가 표시된다. 동점이면 대항한 쪽이 이긴다
- [ ] 먼저 굴린 쪽이 다시 굴리면 승패도 다시 계산된다

### 권한·공개
- [ ] 다른 사람의 판정 카드에는 [확정]·[다시 굴리기]가 보이지 않는다
- [ ] 굴림 공개 설정(GM에게만 등)이 판정 카드에도 적용된다

### GM 판정 요청
- [ ] GM 스크린의 [판정 요청], 또는 토큰 도구의 주사위 아이콘으로 연다(토큰을 선택해 두면 그 캐릭터가 미리 체크된다). 플레이어에게는 보이지 않는다
- [ ] 캐릭터(여럿 가능)·능력치·수정치·목표값·메모·공개 범위를 정해 보내면, 그 캐릭터를 소유한 접속 중 플레이어에게 팝업이 뜬다
- [ ] 팝업에서 사용할 【FP】를 넣고 [실시]하면 바로 굴려져 카드에 「GM 요청: 메모」가 붙는다
- [ ] [거절]하거나 창을 닫으면 GM에게 거절 알림이 뜬다
- [ ] 같은 캐릭터를 두 플레이어가 소유하면 한 명이 응답할 때 다른 쪽 팝업이 닫힌다
- [ ] 소유 플레이어가 접속하지 않았으면 GM에게 팝업이 뜬다

## 단계 3 — 장비·인벤토리 (v0.4.0 ~ v0.4.7)
👥 = GM과 플레이어 계정이 함께 접속해야 확인할 수 있는 항목

### 0. 준비
- [ ] 시스템을 v0.4.7로 업데이트하고 월드에 다시 들어간다
- [ ] 업데이트 전에 월드로 가져온 장식·백팩·텐트·못·쐐기·횃불·기름은 효과·사용 횟수 데이터가 없다. 지우고 컴펜디움에서 다시 가져온다
- [ ] 테스트용 캐릭터에 클래스(예: 소드맨)를 끌어 놓고, 플레이어 한 명에게 소유권을 준다

### 1. GM 스크린
- [ ] 액터 탭 위쪽에 [GM 스크린] 버튼 하나만 있다(GM에게만). 토큰 도구에도 책 아이콘이 있다
- [ ] 위쪽 버튼: [판정 요청] [상점 닫힘/열림] [판매 품목 설정] [추가 품목 폴더] [세션 시작(【FP】 n)]. 버튼에 마우스를 올리면 설명이 나온다
- [ ] 「파티」 탭: 플레이어가 소유한 캐릭터마다 Lv·【HP】·【TP】 막대·【FP】·소지 n/m·G·열. 접속하지 않은 플레이어 이름 옆에 ●. 이름을 누르면 시트가 열린다
- [ ] 캐릭터의 【HP】·소지품 등을 바꾸면 GM 스크린이 바로 갱신된다
- [ ] [세션 시작]: 확인 창 → 파티 전원의 【FP】가 설정값(기본 1)이 되고 채팅에 기록된다
- [ ] 「참고표」 탭: 목표값 기준(7~30), 능력치별 판정, 트랩 대미지 기준, 세션 경험점, 레벨표

### 2. 장비 슬롯·장비 가능 판정
- [ ] 캐릭터 시트에 「능력치」「장비·소지품」「스킬」「해설」 탭. 「스킬」 탭에 클래스와 스킬 목록
- [ ] 「장비·소지품」 위쪽에 무기·갑옷·기타 슬롯 3개, 그 아래 무기 성능 한 줄, 종류별 소지품 목록
- [ ] 장비 팩의 검을 끌어 놓고 방패 아이콘(장비)을 누르면 무기 슬롯으로. 다른 무기를 장비하면 앞의 것은 소지품으로 돌아간다
- [ ] 교체 아이콘(서브웨펀)을 누르면 기타 슬롯에 「(서브웨펀)」으로 들어간다. 서브웨펀의 성능·제련은 부능력치에 더해지지 않는다
- [ ] 슬롯의 ⊗ 아이콘(장비 해제)으로 소지품으로 돌아간다
- [ ] 메인·서브 클래스 모두 못 쓰는 무기, 메인 클래스가 못 입는 갑옷, 어느 쪽도 못 드는 방패는 경고와 함께 장비되지 않는다. GM은 Shift+클릭으로 무시
- [ ] 방패·장식은 기타 슬롯으로 들어간다. 클래스가 없으면 무기·방어구는 장비할 수 없다(장식은 가능)

### 3. 성능·보정
- [ ] 무기 슬롯이 비어 있으면 무기 줄에 「맨손(주먹) · 물리 공격 Lv」, 【물리 공격】= 【STR】B + Lv. 《주먹 마스터리》 스킬이 있으면 (Lv×3)+4
- [ ] 무기 R을 바꾸면 아이템 시트 「성능」과 캐릭터의 【물리 공격】【물리 명중】【속도】가 함께 바뀐다(검 R3 물리 공격 14, 세검 명중 +1·속도 +3)
- [ ] 갑옷+방패를 장비하면 【방어】 = 두 방어의 합, 【회피】·【속도】에 보정(중갑 R2: 방어 9·회피 −2·속도 −6)
- [ ] 「힘의 반지」를 장비하면 능력치 표 「장비」 열에 +3, 최종값·B·부능력치가 바뀐다. 「삶의 벨트」는 【HP】 최대 +8
- [ ] 내성 칸은 「기본」(입력)과 「최종」(장비 포함) 두 줄이다. 〈염〉 내성+1 제련 방어구를 장비하면 〈염〉 최종이 4(파란색)가 되고 기본은 3 그대로
- [ ] 아이템 시트: 무기 종류·속성·슬롯·방어구 종류·소재 종류는 선택 상자. 무기·방어구는 「성능」과 「제련 (n/2)」 목록(배지 + 이름, GM은 ✕로 지울 수 있음, 환불 없음)
- [ ] 제련 배지: 소지품·장비 슬롯의 무기·방어구 이름 옆에 붙은 제련이 배지로(🔥〈염〉·❄〈빙〉·⚡〈뇌〉 속성 부여, 점선 테두리는 내성, 초록 STR+1 등 능력치, 보라 물명+1 등 부능력치), 남은 칸은 ○
- [ ] 시트의 소지품에는 매각(동전)·제련(망치) 아이콘이 없다(상점에서만)

### 4. 소지 수
- [ ] 「소지 n / m」: 장비 중인 것은 세지 않고, 소모품·소재는 수량만큼 센다. 한도를 넘으면 빨갛게. 위쪽 자원 칸에도 같은 값
- [ ] 소지품의 수량 칸을 직접 고칠 수 있다
- [ ] 백팩을 가지면 한도 +4, 백팩 자체는 세지 않는다. 백팩 2개째는 사거나 끌어 놓아도 들어오지 않는다

### 5. 상점 열기·품목 관리(GM)
- [ ] 상점이 닫혀 있으면 플레이어 시트의 [상점] 버튼이 회색(마우스를 올리면 「GM이 열어야 이용할 수 있다」). GM은 언제나 열 수 있다
- [ ] 👥 GM 스크린(또는 토큰 도구 가게 아이콘)으로 열면 모두에게 「상점이 열렸다」 알림, 플레이어 [상점] 버튼이 눌린다. 닫으면 플레이어가 열어 둔 상점 창이 닫힌다
- [ ] [추가 품목 폴더]: 아이템 탭에 「상점 추가 품목」 폴더가 생긴다(이미 있으면 안내만). 이 폴더(하위 폴더 포함)의 무기·방어구·장식·소모품·기타 아이템이 상점에 「추가」 표시로 나온다. 소재는 나오지 않는다
- [ ] 추가 품목 무기·방어구는 아이템에 적힌 R이 기본값. 가격은 종류 표 R식, 그 밖은 아이템의 「가격」, 소재 조건은 아이템의 필요 소재
- [ ] [판매 품목 설정]을 누르면 GM 스크린 「상점 품목」 탭으로 이동한다. 종류별 체크 상자. 「아리아드네의 실」 체크를 끄면 플레이어 상점에서 사라진다
- [ ] 👥 플레이어가 상점 창을 열어 둔 상태에서 숨기면 그 창에서도 바로 사라진다
- [ ] GM이 연 상점에는 숨긴 품목이 「숨김」 표시와 함께 보인다
- [ ] 종류별 [전부 판매]/[전부 숨김], 이름 검색(검색 중이면 보이는 것만 일괄 전환), 「판매 중 / 전체」 개수
- [ ] 「상점 추가 품목」 폴더에 아이템을 넣거나 빼면 「상점 품목」 목록과 열린 상점이 갱신된다

### 6. 구입
- [ ] 탭: 무기·방어구·장식·소모품·기타 아이템. 무기·방어구는 R(기본 = 캐릭터 Lv), 모든 품목은 수량(×). 바꾸면 합계가 바뀐다(검 R2 400G, ×3 → 1200G)
- [ ] [구입] → 확인 창: 「이름 × 수량 — 개당·합계」, 쓸 소재(R이 낮은 것부터 자동 배정), 소지금 전→후
- [ ] 무기·방어구는 개당 대응 소재 1개(R 이상). 소재가 수량만큼 없으면 「필요한 소재가 없다: … ×수량」
- [ ] 메디카 II는 「풀 R4」가 필요하다. R5 풀로는 살 수 없다(R이 정확히 같아야 함)
- [ ] 「캐릭터 작성 중」을 체크하면 소재 없이 G만으로 산다
- [ ] 소지금이 모자라면 살 수 없다
- [ ] 같은 소모품·기타 아이템은 수량에 합쳐진다. 무기 ×2는 무기 아이템 2개가 생긴다
- [ ] 농기구는 살 때 〈참〉〈괴〉〈돌〉 중 속성을 고른다
- [ ] 무기·방어구 구입 확인 창에 「이름」 칸(기본값 = 원래 이름). 바꾸면 그 이름으로 들어오고, 비워 두면 원래 이름. ×2면 둘 다 같은 이름
- [ ] 소모품·장식 등은 이름 칸이 없다
- [ ] 구입은 채팅에 기록된다(수량·소재 포함)

### 7. 매각·제련 (상점 안에서만)
- [ ] 상점 창에 「매각」「제련」 탭이 있다. 상점이 닫혀 있으면 플레이어는 상점 자체를 열 수 없다(GM은 가능)
- [ ] 「매각」 탭: 창고에 없는 물건 전부(장비 중인 것은 「장비 중」 표시). 줄마다 체크 상자, 수량이 여럿이면 수량 칸(기본 전부)
- [ ] 체크하거나 수량을 바꾸면 아래 「합계 nG」가 바로 바뀐다. 아무것도 안 고르면 [고른 것 매각]이 눌리지 않는다
- [ ] [소재 전부 고르기]로 소재가 한꺼번에 체크된다
- [ ] [고른 것 매각] → 확인 창: 목록·줄별 가격·합계·소지금 전→후(장비 중인 것이 섞이면 빨간 경고) → 판매. 채팅에 한 줄로 기록
- [ ] 판매가: 구입가의 50%(검 R2 → 200G), 소재는 R²×50G. 수량 일부만 팔면 나머지가 남는다
- [ ] 「제련」 탭: 창고에 없는 무기·방어구(주먹 제외), 현재 배지와 빈칸 ○, 대응 소재. 2칸이 다 차면 [제련]이 눌리지 않는다
- [ ] [제련] → 효과 선택(무기용·방어구용만, 이미 붙은 것은 회색). 상점의 「캐릭터 작성 중」이 체크돼 있으면 제련 창에서도 체크된 채 열린다
- [ ] 제련: 대응 소재 R 이상 1개 + 가격(【STR】+1, R3 → 450G). 채팅에 기록. 끝나면 탭의 배지가 갱신된다
- [ ] 제련한 효과는 장비 중일 때만 보정이 적용된다

### 8. n회분·사용
- [ ] 못·쐐기를 사면 소지품에 「5/5」, 소지 수는 1만 늘어난다
- [ ] 손 아이콘([사용])을 누르면 「4/5」로 줄고 채팅에 해설과 「이 세트 4/5 남음」. 5번 쓰면 그 세트가 없어진다(2세트였으면 수량 1, 다시 5/5)
- [ ] 메디카 같은 소모품, 「소모품」이라고 적힌 기타 아이템(횃불·기름)도 [사용]으로 1개 줄어든다. 효과는 아직 자동 적용되지 않는다(채팅에 안내)
- [ ] 10m 로프·텐트처럼 반복해서 쓰는 물건에는 [사용] 버튼이 없다

### 9. 창고
- [ ] 게임 설정 → 시스템 설정 「창고 기능」이 꺼져 있으면 창고 관련 표시가 전혀 없다(GM 스크린의 「창고」 열 포함)
- [ ] 켜면 GM에게만: 캐릭터 시트 「장비·소지품」 아래 「이 캐릭터의 창고 허용(GM)」 체크, GM 스크린 「파티」의 「창고」 열 체크
- [ ] 허용하면 소지품 목록 바로 아래 「창고」 구역, 소지품마다 창고 아이콘(창고로). 장비 중인 것에는 없다
- [ ] 수량이 여럿이면 몇 개를 옮길지 묻는다. 같은 소재(종류·R)·같은 소모품은 창고 안에서 합쳐진다
- [ ] 창고의 물건은 소지 수에 들어가지 않는다. 창고의 백팩은 한도를 늘리지 않는다. 창고의 소재로는 구입·제련할 수 없다. 창고의 물건에는 [사용]이 없다
- [ ] 「꺼내기」: 소지 수가 넘치면 정리 창(버리기·창고로)
- [ ] 창고 기능을 끄거나 캐릭터 허용을 해제하면 창고 구역이 사라진다. 다시 켜면 넣어 둔 물건이 그대로 있다

### 10. 소지 수 초과
- [ ] 👥 소지 수가 한도인 캐릭터 시트에 GM이 소재를 끌어 놓으면, 소유 플레이어(접속 중)에게 「소지 수 초과」 창이 뜨고 GM에게는 「정리를 맡겼다」 알림
- [ ] 창 위쪽 「새로 들어올 것」에 「두고 가기」, 아래 「지금 가진 것」에 「버리기」. 「창고로」 칸은 없다(던전 획득은 창고 불가)
- [ ] 소재 3개 중 1개만 두고 가는 식으로 일부만 챙길 수 있다. 「정리 후 n / m」이 한도 안이어야 [이대로 받기]가 눌린다
- [ ] [전부 두고 가기]를 누르면 아무것도 들어오지 않는다
- [ ] 소유 플레이어가 접속해 있지 않으면 GM에게 창이 뜬다
- [ ] 상점에서 살 때 넘치면 같은 창이지만 「두고 가기」는 없고(전부 아니면 취소), 창고가 허용돼 있으면 「창고로」 칸이 있다. 이번 구입에 쓸 소재는 「이번에 쓸 소재 n개 제외」로 표시되어 버릴 수 없다. [취소]면 G·소재도 소모되지 않는다

### 2. 프리셋 만들기

- [ ] [프리셋 만들기]: 이름 → 씬 탭 「전투 프리셋」 폴더에 씬이 생기고 그 씬으로 이동, 씬 설정 창이 열린다

- [ ] 새 프리셋 씬과 전투 사본 씬은 토큰 시야가 꺼져 있어 플레이어도 토큰과 관계없이 화면 전체가 보인다

- [ ] 「전투」 탭에 프리셋이 썸네일·에너미 목록·BGM과 함께 나오고, 씬을 바꾸면 바로 갱신된다. 눈(씬 보기)·톱니(씬 설정)

### 3. 에너미 놓기
- [ ] 컴펜디움 「에너미」 팩에서 숲쥐를 프리셋 씬 위쪽 줄에 여러 번 끌어 놓는다 → 액터 탭에는 「프리셋 에너미」 폴더에 숲쥐 1개만 생긴다. 다른 프리셋에 놓아도 같은 숲쥐 액터를 쓴다
- [ ] 액터 탭의 에너미(「프리셋 에너미」의 것, 복제해 만든 변형)를 끌어 놓아도 된다
- [ ] 어디서 놓든 에너미 토큰은 액터와 연결 안 됨이다. 프리셋 씬의 에너미 토큰을 「액터와 연결」로 바꾸려 하면 경고와 함께 막힌다
- [ ] 프리셋 씬의 토큰 하나를 더블클릭해 【HP】 등을 고치면 그 토큰만 바뀐다(같은 맵의 다른 숲쥐·숲쥐 액터는 그대로)
- [ ] 숲쥐 액터를 복제해 「숲쥐 보스」로 이름과 【HP】를 바꾼 변형: 컴펜디움 숲쥐를 끌어 놓을 때 변형이 아니라 기본 숲쥐가 쓰인다
- [ ] [에너미 정리]: 이름·이미지·능력치가 완전히 같은 중복만 합쳐지고(토큰은 정상), 변형은 그대로. 원본 표시가 없는 예전 액터도 이름으로 시스템 에너미로 알아본다
- [ ] 프리셋 씬을 지운 뒤 [에너미 정리]를 하면, 그 프리셋에서만 쓰던 에너미가 「안 씀」으로 체크돼 나온다(다른 프리셋에서 쓰는 것은 그 씬 이름이 표시되고 체크 불가)

### 4. 희소종
- [ ] 프리셋 씬의 숲쥐 토큰 하나를 더블클릭 → 시트 위쪽 GM 전용 [★ 희소종으로] → 【HP】 ×2/×3, GM 재량 강화는 【물리 명중】【속성 명중】【회피】(+1)·【물리 공격】【속성 공격】【방어】(+2)를 항목별로 체크(바뀔 값이 옆에 표시)

- [ ] [희소종 해제]로 원래 값으로 돌아간다
- [ ] 이름은 바뀌지 않는다. GM 스크린 「전투」 탭 에너미 목록과 전투 추적기에 ★가 붙고, 플레이어 화면에는 ★가 없다

### 5. 전투 개시

- [ ] 👥 개시하면 지금 음악이 멈추고, 모두의 화면이 「(프리셋 이름) [전투 중]」 씬으로 넘어가며 그 씬의 BGM이 재생된다
- [ ] 파티 토큰은 아래 두 줄(전위·후위 각 3칸)에, 에너미는 놓인 높이로 전위·후위·왼쪽부터 순서대로 가운데 정렬. 많으면 간격이 좁아진다

- [ ] 전투가 자동으로 시작되고(1턴 개막 페이즈) 전투 추적기 탭이 열린다. 채팅에 「전투 개시」 카드(기습이면 빨간 안내)
- [ ] 희소종 토큰은 희소종 능력치로 싸운다
- [ ] 전투 중에는 [전투 개시] 자리가 [전투 종료 (프리셋 이름)]이 되고, 다시 개시할 수 없다

### 6. 행동 순서·페이즈

- [ ] 【속도】가 바뀌면(장비 등) 다음 메인 페이즈 시작 때 순서가 다시 계산된다

### 7. 개막 행동
- [ ] 개막 페이즈에 자기 캐릭터(플레이어) 또는 GM에게 방패·화살표·교체 아이콘
- [ ] 방패(방어 전념): 누르면 그 방패 버튼이 파란 바탕으로 켜진다(버튼 위치는 그대로, 마우스를 올리면 「방어 전념 해제」). 다시 누르면 해제. 채팅에 기록
- [ ] 메인 페이즈에는 방어 전념 중인 전투원 옆에 파란 「방어」 표시가 붙고, 그 전투원의 차례는 건너뛴다
- [ ] 화살표(배치 변경): 전위·후위 3칸씩 나온 창에서 빈 칸을 고르면 토큰이 그 칸으로 옮겨진다. 다른 사람이 있는 칸은 고를 수 없다. 칸은 캐릭터마다 기억된다(다음 전투에도 같은 자리)
- [ ] 에너미의 화살표(GM): 열과 순서를 정하면 그 줄에서 다시 정렬된다
- [ ] 교체(무기 교체): 무기 슬롯과 기타 슬롯의 무기가 바뀐다(둘 다 무기일 때만, 아니면 경고)
- [ ] [도주 판정](GM): 확인 → 살아 있는 전원이 【회피】로 굴리고, 도주 측 최고 > 추격 측 최고면 성공(동점 실패). 결과 카드

### 8. 통상 공격
- [ ] 👥 메인 페이즈가 시작되면 전투에 참가한 플레이어의 왼쪽 도구가 자동으로 「타겟 선택」(과녁)으로 바뀐다. 개막·종료 페이즈, 전멸, 전투 종료 때는 「토큰 선택」으로 돌아온다. 메인 페이즈 도중에 접속해도 맞춰진다(GM은 바뀌지 않음)
- [ ] 👥 「토큰 선택」 도구 상태에서도 메인 페이즈에 전투 씬에서 다른 토큰을 클릭하면 그 토큰 하나만 타겟이 된다(다시 클릭하면 해제). 자기 토큰과 현재 차례인 토큰은 평소처럼 선택된다. GM도 같다
- [ ] 👥 플레이어: 자기 차례에 에너미 토큰을 클릭(타겟) → 시트 머리 [통상 공격] 또는 트래커의 주먹 아이콘
- [ ] 👥 플레이어가 자기 차례가 아닐 때(또는 메인 페이즈가 아닐 때) 공격하면 「○○의 차례가 아니다」 경고만 나오고 굴리지 않는다
- [ ] GM이 차례가 아닌 캐릭터·에너미로 공격하면 굴리기 전에 「차례가 아니다, 그래도 공격할까?」 확인 창
- [ ] 공격 카드: 명중 2D6 + 【물리 명중】 vs 【회피】, 명중/빗나감. [6,6] 절대 성공, [1,1] 절대 실패
- [ ] 명중: 대미지 (【물리 공격】 − 【방어】)D6, 내성보다 큰 눈이 진하게, 실대미지 = 그 개수
- [ ] 무기 속성의 내성을 쓴다. 속성 부여 제련이 있으면 복합 속성(둘 중 낮은 내성). 무기가 없으면 맨손(주먹, 〈괴〉)
- [ ] 6이 1보다 2개 이상 많으면 「크리티컬」 +4D6
- [ ] 방어 전념 중인 대상은 실대미지 절반(「방어 전념 절반」)
- [ ] PC의 명중 판정에서 1이 나오면 【FP】 +1
- [ ] 사거리 「근」: 공격자나 대상이 후위면 경고. 같은 편 지정·대상 0개·2개 이상이면 경고. GM은 Shift+클릭으로 사거리·같은 편 무시
- [ ] GM: 전투 씬의 에너미 토큰 시트에서 [통상 공격]으로 PC 공격

### 9. 적용(자동 적용 설정)
- [ ] 👥 「확인 후 적용」: GM에게만 [적용]. 누르면 대상 【HP】가 줄고 [되돌리기]로 원래대로
- [ ] 👥 「식별 전」으로 개시한 전투: GM 카드에는 「적용됨: 【HP】 a → b」, 플레이어 카드에는 「적용됨」만(내성·대미지 눈·실대미지는 보인다). 에너미 시트의 「식별」을 체크하면 플레이어에게도 【HP】 변화가 보인다
- [ ] 👥 「식별 성공」으로 개시하면 플레이어에게도 【HP】 변화가 보인다. PC가 맞을 때는 언제나 보인다
- [ ] GM: 전투 추적기의 에너미마다 눈 아이콘(감은 눈 = 식별 전, 뜬 파란 눈 = 식별됨). 누를 때마다 바뀐다. 플레이어에게는 안 보인다
- [ ] GM: 식별 전 에너미가 남아 있으면 페이즈 막대에 [모두 식별]. 누르면 남은 에너미 전부 식별됨
- [ ] 👥 식별하면 채팅에 「○○을(를) 식별했다」, 이미 지나간 공격 카드에서도 그 에너미의 「【HP】 a → b」가 플레이어에게 보이게 된다
- [ ] 👥 「즉시 적용」: 플레이어가 공격하면 GM 쪽에서 바로 에너미 【HP】가 줄어든다(단계 4 완료 기준)
- [ ] 「끔」: 버튼 없이 「GM이 직접 고친다」 안내만
- [ ] 【HP】가 0 이하가 되면 트래커에 전투 불능(해골), 차례도 건너뛴다. 다시 올리면 해제(손으로 고쳐도 같다)
- [ ] 한 진영의 전위가 전원 전투 불능이면 전위·후위가 바뀌고 토큰이 새 칸으로 옮겨진다. 채팅에 안내
- [ ] 에너미가 전원 전투 불능이면 채팅에 「에너미 전멸」, 트래커 막대가 노란 「에너미 전멸 — 전투를 끝낸다」와 GM [전투 종료(승리)] 버튼으로 바뀐다(파티 전멸이면 「전멸」)
- [ ] 이 상태에서 [다음 차례]·[전투 종료(승리)]를 누르면 턴이 넘어가지 않고 결과 「승리」가 미리 골라진 종료 창이 뜬다
- [ ] 쓰러진 에너미의 【HP】를 되돌리면(되돌리기·직접 수정) 종료 대기가 풀리고 다시 진행할 수 있다
- [ ] 전투 추적기의 기본 「쓰러짐으로 표시」로 에너미를 전부 쓰러짐 처리해도(【HP】는 그대로) 「에너미 전멸」 종료 대기가 된다. 표시를 하나 끄면 풀린다
- [ ] 전위를 전부 「쓰러짐으로 표시」하면 그 진영의 전위·후위가 교대한다
- [ ] 【HP】가 남아 있는 에너미에 GM이 손으로 붙인 「쓰러짐」은, 그 에너미의 【HP】가 바뀌어도 풀리지 않는다. 【HP】 0으로 쓰러진 경우는 【HP】를 되돌리면 자동으로 풀린다

### 10. 전투 종료
- [ ] 👥 [전투 종료] → 결과(승리·도주·전멸·중단) → 채팅에 기록. 원래 씬으로 모두의 화면이 돌아가고, 전투 BGM이 멈추고 원래 음악이 다시 재생된다
- [ ] 사본 씬(「진행 중인 전투」 폴더)은 삭제되고 프리셋 씬은 그대로
- [ ] 전투에서 깎인 PC의 【HP】는 캐릭터 시트에 그대로 남는다
- [ ] 같은 프리셋으로 다시 개시하면 에너미가 처음 상태(【HP】 가득, 희소종 설정은 유지)
- [ ] 전투 추적기의 기본 [전투 종료]로 끝내도 원래 씬·음악으로 돌아가고 사본이 삭제된다. 결과는 전멸 상태였으면 「승리」(또는 「전멸」), 아니면 「중단」

## UI·시트·스킬 트리·에너미 일러스트 (v0.6.0 ~ v0.7.3)
👥 = GM과 플레이어 계정이 함께 접속해야 확인할 수 있는 항목

### 0. 준비
- [ ] 최신 버전으로 업데이트하고 월드에 다시 들어간다(예전 화면이면 Ctrl+F5). 열려 있던 시트는 닫았다 다시 연다

### 1. 테마 공통
- [ ] 캐릭터·에너미·토큰·아이템 시트, 상점, GM 스크린, 스킬 트리, 시스템이 띄우는 대화창(판정·배정·소지 수 초과·판정 요청·배치 변경·능력치 편집 등)이 짙은 남색 바탕·금색 테두리·금색 제목으로 나온다
- [ ] 입력칸·선택 상자·버튼이 어두운 바탕에 밝은 글씨로 읽힌다(흰 바탕에 흰 글씨 같은 곳이 없다)
- [ ] 다른 시스템·모듈의 창(일기, 씬 설정 등)은 원래 모습 그대로다

### 2. 캐릭터 시트 — 머리·「능력치」 탭
- [ ] 머리: 얼굴(클릭하면 이미지 변경), 이름, Lv·메인/서브 클래스·열, 【HP】·【TP】 막대(값 입력 가능), 오른쪽에 【FP】·소지금·소지 n/m·경험점
- [ ] 메인/서브 클래스 이름(「다크 헌터」 등)이 잘리지 않는다
- [ ] 머리 아래 버튼 줄: [통상 공격], [능력치 굴리기](작성 잠금 전), GM에게 「동료 NPC」
- [ ] 능력치 카드 5장(최종값 크게, B): 클릭(숫자·이름) = 판정 대화창, Shift+클릭 = 바로 굴림. 마우스를 올리면 굴림·클래스·성장·GM 보너스·장비 내역. 장비·GM 보너스로 바뀐 카드는 하늘색 테두리
- [ ] 내성 6칸: 큰 숫자 = 최종, 아래 칸 = 기본 입력, 장비로 바뀐 값은 하늘색
- [ ] 부능력치 3×3이 「물리 명중·속성 명중·회피·물리 공격·속성 공격·방어·억제 공격·억제 방어·속도」로 보인다(영어 키 없음)
- [ ] 장비 요약은 가로줄 3개: 칸 아이콘·이름, 아이템 그림, 이름(길면 줄바꿈), R, 제련 배지. 무기가 없으면 맨손 표시. 그림·이름을 누르면 아이템 시트
- [ ] 소지품 요약·제련 배지도 「물리 공격」「속성 공격」(속공 아님). 속성 부여 제련은 「불 속성」처럼 보인다
- [ ] 「장비·소지품」「스킬」「해설」 탭도 같은 디자인

### 3. 능력치 편집
- [ ] 「능력치」 제목 오른쪽 [능력치 편집]: 한 창에 STR~LUC 다섯 줄, 열은 굴림·클래스·성장·GM 보너스·장비·최종·B. 한 능력치가 한 줄에 다 들어간다
- [ ] 값을 고치면 저장 전에 최종·B가 바로 바뀐다. 저장하면 시트에 반영된다
- [ ] 「일시」 열이 없다. v0.6.0에서 일시에 넣어 둔 값이 있던 캐릭터는 그 값이 GM 보너스에 더해져 보이고 최종값은 그대로다
- [ ] 👥 플레이어: 굴림(잠금 전)·성장만 입력칸, GM 보너스는 숫자만 보인다(최종값에는 더해진다)

### 4. 캐릭터 작성 기록·잠금(GM)
- [ ] GM이 보는 「능력치」 탭 아래에 「캐릭터 작성 기록(GM)」 패널(플레이어에게는 없음): 능력치 굴리기 횟수, 굴린 값(순서대로)·합계·초기 소지금, 배정, 기록 목록
- [ ] 👥 플레이어가 [능력치 굴리기]를 여러 번 하면 GM 패널의 횟수와 기록이 늘어난다
- [ ] [작성 완료 — 잠그기]: 플레이어 시트에서 [능력치 굴리기]가 사라지고, 능력치 편집 창의 「굴림」이 숫자만 보인다. 채팅 카드의 [배정하기]도 막힌다. 「성장」은 계속 고칠 수 있다
- [ ] GM은 잠근 뒤에도 굴림을 고칠 수 있고, 굴림·GM 보너스를 고친 내역(「STR 굴림: 14 → 15」)이 기록에 남는다
- [ ] [잠금 풀기]로 되돌릴 수 있다

### 5. 스킬 탭
- [ ] 위에 클래스 카드(메인·서브), 그 아래 [전체 n] [전투 스킬 n] [비전투 스킬 n] 분류 버튼과 [스킬 트리] 버튼
- [ ] 가진 스킬이 「(메인 클래스) · 메인 클래스」「(서브 클래스) · 서브 클래스」「커먼 스킬」「그 밖의 스킬」 구역으로 나뉜다
- [ ] 스킬 줄: 고유 스킬 ★, 비전투 스킬은 나침반 아이콘, 타이밍 배지(상시 초록·주행동 주황·수동 보라·개막 하늘), 코스트, SL/MaxSL(서브 클래스 스킬은 서브 MaxSL), 마우스를 올리면 전제 조건
- [ ] 분류를 누르면 그 분류의 스킬만 보인다. 분류는 창을 닫기 전까지 기억한다(보는 사람마다 따로)
- [ ] 자동 분류: 커먼 스킬은 비전투. 「상시」「특수」는 해설로 판정(추적·와이어 스턴트·물거미·큰 바구니·왕의 증표 등은 비전투, 전력 도주·가디언 등은 전투). 주행동·개막·수동은 전투
- [ ] GM이 스킬 아이템 시트의 「전투/비전투」를 바꾸면 분류가 바뀐다(기본 「자동 판정(…)」)

### 6. 스킬 트리
- [ ] [스킬 트리]: 탭 「(메인 클래스) · 메인」「(서브 클래스) · 서브」「커먼」. 전제 조건이 있는 스킬은 왼쪽→오른쪽 트리, 아래에 「선행 조건 없는 독립 스킬」
- [ ] 선은 직각으로 꺾이고, 부모마다 선 색이 조금씩 다르다. 채운 전제의 선은 금색. 선 끝 동그라미 = 필요한 SL(전제가 둘이면 배지가 겹치지 않게 나란히)
- [ ] 「A 또는 B」 전제는 「또는」 분기점 하나로 모인다(다크 헌터: 검·세검·채찍 마스터리 → 「또는」 → 각 스킬)
- [ ] 스킬에 마우스를 올리면 그 스킬의 선행·후속 사슬만 하늘색으로 밝아지고 나머지는 흐려진다
- [ ] 스킬 칸: 이름(고유 ★), 가진 SL(굵게), MaxSL 「메인/서브」. 마우스를 올리면 타이밍·코스트·전제·해설 앞부분, 습득할 수 없으면 이유
- [ ] 색: 습득 가능 = 하늘색 테두리, 가진 것 = 금색, 최대 = 빛나는 금색, 조건 미충족 = 어두운 칸(뒤로 선이 비치지 않음)
- [ ] 클릭하면 SL +1(처음이면 스킬이 시트에 추가된다), 우클릭하면 −1(0이면 지워진다). 시트의 스킬 탭도 바로 바뀐다
- [ ] 위쪽 「남은 SL n / m」: Lv1은 5, 레벨마다 +3. 커먼 스킬 첫 1SL과 고유 스킬은 세지 않는다. 다 쓰면 더 올릴 수 없다는 알림
- [ ] Lv1에서는 한 스킬 SL 2까지(레벨마다 +1), MaxSL까지
- [ ] 서브 탭: MaxSL 서브 값까지, 「-」는 습득 불가. 서브 클래스가 있으면 고유 스킬(★) 불가
- [ ] 메인·서브에 같은 이름 스킬(예: 소드맨 + 다크 헌터의 검 마스터리)이 있으면 서브 탭의 그 칸에 「메인」 표시와 메인 쪽 SL·MaxSL(메인 값)이 보이고, 클릭·우클릭하면 메인 스킬이 오르내린다. 시트에는 스킬이 하나만 있다
- [ ] 서브 트리에서 그 스킬을 전제로 하는 스킬은 메인 쪽 SL로 전제를 채운다
- [ ] 다른 스킬의 전제가 되는 스킬을 우클릭으로 내리면 확인 창이 뜬다
- [ ] GM은 Shift+클릭으로 조건을 무시하고 올릴 수 있다
