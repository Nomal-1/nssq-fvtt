# 데이터 레퍼런스 (Data Reference)
캐릭터 작성과 세션 진행에 쓰는 데이터 모음. 원문 사이트의 '데이터' 메뉴 구성을 따랐다.
- **클래스 일람**: 31개 클래스의 능력치 보정, 장비 가능 무기·방어구, 스킬 목록 (데이터베이스)
- **커먼 스킬**: 클래스와 관계없이 누구나 배울 수 있는 스킬
- **무기·방어구 / 아이템 / 소재**: 쇼핑과 생활 룰에서 쓰는 장비·소모품·소재 데이터
- **에너미**: GM용 에너미 65종 (Lv1 / Lv2 / Lv3\~4 / F.O.E.)
