# 07. 미결 사항

원문에 명시가 없어 **임시 처리**를 정해 둔 항목이다. 구현은 임시 처리대로 하되, 해당 지점에 `// OPEN-QUESTION #n` 주석을 달고, 가능하면 GM이 바꿀 수 있는 설정으로 둔다. 확정되면 01에 반영하고 여기서 지운다.

| # | 질문 | 임시 처리 |
|---|---|---|
| 1 | 대미지 다이스 수가 0 이하일 때 | 대미지 0(다이스를 굴리지 않음) |
| 2 | 크리티컬로 추가한 4다이스로 크리티컬을 다시 판정하나 | 하지 않음 |
| 3 | \[수면\]의 "〈참〉〈괴〉〈돌〉 내성 −1로 취급"이 −1로 설정인지 1 감소인지 | −1로 **설정**(그 속성의 모든 눈이 대미지) |
| 4 | FP로 주사위를 늘린 판정의 절대 성공·실패 판정 기준 | 선택한 2개 기준 |
| 5 | 같은 상태 이상을 다시 부여할 때 | 심도가 더 높으면 갱신, 아니면 무시 |
| 6 | 대결 판정으로 부여한 상태 이상의 심도 | 공격자의 달성값 |
| 7 | 강화·약화 4종류째를 부여할 때 | 거부하고 채팅 카드에 표시(GM이 수동으로 교체 가능) |
| 8 | \[독\] 대미지에 방어·내성 적용 여부 | 적용하지 않음("실대미지" 표기 근거) |
| 9 | 「주행동」 발동 실패 시 코스트 | 소모함 |
| 10 | 커먼 스킬 MaxSL `1/0`과 클래스 스킬 `1/-`의 차이 | 둘 다 "서브로는 습득 불가"로 취급 |
| 11 | glossary에만 있는 강화·약화(공격 상승, 물리 명중 상승, 물리 방어 상승, 억제 공격 상승, 완전 내성 등)의 분류와 대항 관계 | 이름에 '상승'이면 강화, '저하'면 약화, 대항은 같은 대상 수치의 상승↔저하. 완전 내성은 강화·대항 없음 |
| 12 | 연계 공격에서 연계자가 행동 불가일 때 | 사용 불가 |
| 13 | 토큰의 명중·대미지 계산에 쓰는 능력치 | 배치자 값 사용(스킬 해설에 지정이 있으면 그것) |
| 14 | 지연 공격의 발동 시점이 룰(종료 페이즈)과 스킬 해설(다음 턴 후발 행동 등)이 다른 경우 | 스킬 해설 우선(`delayed.at`) |
| 15 | 몽크 무기 표기 `망치(주먹)`의 의미 | 클래스 본문 확인 후 확정. 그때까지 망치·주먹 모두 허용 |
| 16 | 희소종 에너미의 표시 | 원문 데이터에 희소종 표시가 없다. `isRare`는 모두 false로 두고 GM이 시트에서 켠다 |
| 18 | 「일반 행위 판정을 다시 굴린다」의 【FP】 비용(원문은 FP 사용법으로만 소개, 수치 없음) | 1점 소모(`engine/check.mjs`의 `REROLL_COST`) |
| 19 | 대항 판정에서 양쪽 모두 절대 실패 | 동점과 같이 수동 측 승리 |
| 20 | 무기를 장비하지 않은 캐릭터의 공격 | **확정(사용자)**: 무기 슬롯이 비면 주먹(맨손) 행을 쓴다. 【물리 공격】= 【STR】B + Lv(《주먹 마스터리》면 (Lv×3)+4), 〈괴〉 |
| 21 | 기타 슬롯의 서브웨펀에 붙은 제련·성능 | 교체용이므로 적용하지 않는다. 무기 슬롯으로 바꿔 장비하면 적용 |
| 22 | 제련한 장비의 매각가 | 제련비는 포함하지 않고 장비 구입가의 50% |
| 23 | 아이템 「필요 소재 풀 R4」의 R 조건 | **확정(사용자)**: R이 **정확히 같은** 소재만. 무기·방어구는 원문대로 R 이상 |
| 24 | 제련 「〈염〉 속성 부여」와 무기 기본 속성의 관계(교체인지 복합인지) | 강화 『속성 부여』 원문(「공격의 기본 속성에 지정 속성이 더해진다」)과 같이 **더한다** → 복합 속성, 내성은 최저 |
| 25 | 에너미 통상 공격의 사거리(데이터에 없음) | 「근」으로 본다. GM은 Shift+클릭으로 사거리 무시 |
| 26 | 공격 명중 판정에서 【FP】 주사위 추가·다시 굴리기 | 단계 4에서는 지원하지 않음(1로 【FP】 획득만). 스킬 사용 흐름(단계 6)에서 다시 정한다 |
| 27 | 방어 전념의 「턴 종료까지」 | 그 라운드의 종료 페이즈가 끝나고 다음 라운드가 시작될 때 해제 |
| 28 | 능력치의 「일시」 보정이 필요한가 | 룰에서 능력치를 바꾸는 것은 장식·제련(장비)뿐, 강화·약화는 부능력치 → 「일시」를 없애고 GM 보너스만 둔다(기존 값은 GM 보너스로 합산) |
| 29 | 스킬의 전투/비전투 구분(데이터에 없음) | 커먼 스킬은 비전투. 그 밖에는 타이밍 「상시」·「특수」이고 해설에 전투 관련 말(【부능력치】·대미지·명중·분류·라운드·도주·능동 회피 등)이 없으면 비전투. GM이 스킬 시트에서 고칠 수 있다 |
| 30 | 레벨업 때 「한 스킬 SL은 1만」 | 기록하지 않고 상한으로 본다: 한 스킬 최대 SL = Lv + 1(Lv1은 2). 합계 SL = 5 + 3×(Lv−1), 작성 때 커먼 스킬 1SL과 고유 스킬(★)은 따로 |
| 31 | 전투 중 화면(씬 이동 여부) | (사용자 결정) 씬을 옮기지 않는다. 필드 씬 위에 원작풍 전투 화면(HTML)을 덮고 [맵 보기]로 접는다. 전투원 데이터는 화면에 띄우지 않는 프리셋 사본 씬의 토큰에 두고, 전투(Combat)는 씬에 묶지 않는다 |
| 17 | 무기 표의 `주먹(주먹 마스터리)` 행 | 별도 무기가 아니라 주먹의 【물리 공격】 대체 식으로 본다(`table.physAtkAlt`, 《주먹 마스터리》 습득 시) |
